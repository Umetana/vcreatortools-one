# VCT Stage FX v1.0.0

1920×1080のステージ上で、コメント配置・表示方式・カード装飾・画面演出をまとめて設定する、わんコメ用テンプレートです。

**初回公開版 v1.0.0（2026-09-17採番）。** Chromeで模擬入力による検証を実施し、ユーザー環境のOBSでもコメント表示・画面演出・マウス配置編集を含む一通りの操作を確認済みです。長時間運用は実際の使用を通じて継続確認します。

## 使い方

1. このフォルダをわんコメのカスタムテンプレートフォルダに配置します。
2. OBSへブラウザソースとして追加し、幅1920・高さ1080を指定します。基本はローカルファイル運用で、新たなサーバーやビルドは不要です。
3. OBSの「対話」を開き、描画エリア右下の歯車から設定を開きます。
4. 「コメント配置」で位置・領域の幅と高さ・全体倍率を調整します。スライダー、数値入力、上下矢印を使えます。X・Y・幅・高さはスライダー5px刻み、数値入力と上下操作は1px刻みです。数値入力はEnterまたは欄を離れると確定します。
5. 「コメント表示」で縦積み・ポップアップ・Underbar、「コメント装飾」でハート・Flash・Stars、「画面演出」で支援・メンバー時の演出を選びます。
6. 「コメントを試す」「演出を試す」で確認し、「保存して再読み込み」で全タブの設定をまとめて保存します。

タブ切替では未保存値を保持します。×で閉じると未保存設定を取り消します。設定パネルは左右移動・折りたたみが可能です。初期値は透明背景、左側の縦積み、支援・メンバーにハート4個、画面演出はサークルです。

「領域全体の倍率」は文字・カード・装飾を一緒に拡縮します。領域の幅・高さ、ポップアップやUnderbarのカード幅・倍率は別設定です。ポップアップの全面ランダムとUnderbarは、自動でステージ全面1920×1080・領域倍率1を使用します。指定コメント領域の数値は上書きせず、基準位置モードや縦積みへ戻すと元の位置・幅・高さ・倍率を適用します。全面ランダムのカード倍率はポップアップ設定、Underbarのカード倍率・下位置はUnderbar設定で調整します。

「領域の外枠」は配置確認用です。ONのまま保存すると配信画面にも表示されるため、配置が決まったらOFFにしてください。「コメント配置」の「マウスで配置調整」を押すと、コメントがなくても表示される編集枠をドラッグして移動し、枠内のホイールで倍率を0.05刻みで変更できます。数値入力にも即時反映され、保存で確定、×で取消になります。設定パネルを折りたたんだ状態でも操作できます。縦積み・ポップアップ基準位置で使用でき、全面ランダム・Underbarでは無効です。タブ切替・設定を閉じる操作で編集モードを終了します。幅・高さは従来の入力で調整します。

## 演出と停止

画面演出は受信時に発火判定し、通常コメントでは発火しません。Underbarの表示待ちとは独立しているため、支援カードが登場する前に画面演出が終了する場合があります。初期版ではこの時間差を許容しています。

- 「画面演出を全停止」：実行中・待機中の画面演出を消します。コメントとカード装飾は残します。
- 「動き抑制」：画面演出とカード装飾を停止します。横流し・横積み・ポップアップなど、コメント表示の移動は継続します。解除しても停止した画面演出は再生し直しません。
- 「支援・メンバーで演出を再生」をOFF：画面演出のみ停止します。

サークル・Halloweenに加え、Heart・Stars・紙吹雪・Sparkleの画面演出を同梱しています。HalloweenはAI生成画像を元に作者が加工した画像を使用し、絵文字表示にも切り替えられます。演出登録の方法は[演出ガイド](effects/README.md)を参照してください。

## 設定の保存・プロファイル

優先順位は `config_default.js → config.js → ローカル保存差分`。ChromeとOBSの保存領域共有は前提にしません。フォルダ名を変えると別の保存先になります。

ローカルファイル運用では常にdefaultです。用途別に分ける場合はフォルダを複製します。既にローカルサーバー経由で使っている場合は、URLへ `?profile=talk` などを付けると、同じフォルダで用途別設定を保存できます。既にクエリがある場合は `&profile=talk` を使用します。編集中のプロファイルは設定パネル上部に表示します。

背景・コメント配置・表示・装飾・画面演出の設定はプロファイル別、演出の登録一覧はフォルダ共通です。登録追加・解除は即時保存され、設定の取消・初期設定・ローカル設定削除では元に戻りません。別プロファイルを開いている画面へ登録変更を反映するには再読み込みしてください。登録解除された演出を選択していた場合は、次の読込時にサークルへ戻ります。

`config.js`は全プロファイル共通の基準値です。「ファイルから読込」は、`window.CONFIG = { "COMMENT_X": 80 };`のようなJSON形式の代入のみ受け付けます。旧Base・V3の設定を自動移行する機能はありません。

`?settings=1`で設定を開いて起動します。`?ui=0`で歯車を含む操作UIを非表示にできます。両方指定した場合は`ui=0`を優先します。

## 制限・確認方法

- コメント領域は1つです。領域端でカード・装飾をクリップします。
- Underbarの本文はV3同様に一行省略です。画面外に保持したカードは内部に残っていても表示されません。
- プレビュー取消で、時間切れ・上限超過・停止により消えたコメントや画面演出は復元しません。
- 強調色が白のギフトは白文字が読みにくくなる場合があります。V3由来の色仕様を継承しており、独自の色補正は行っていません。
- OSにインストール済みのフォントとフォールバックを使います。V3のGoogle Fonts取得は持ち込んでいません。

開発用の状態遷移・表示・保存テスト：`node --test VCT_Stage_FX/tests/*.test.cjs`

Chrome画面検証：PlaywrightをNodeが解決できる開発環境で `node VCT_Stage_FX/tests/browser.cjs`。OneSDKの受信境界だけを模擬し、実運用のコメントやOBSの保存領域には接続しません。30件の単体テストと、表示方式・拡縮・動き抑制・タブ・取消保存・プロファイル・file起動・破棄のブラウザ検証が通過しています。通常・支援・メンバー・固定など9種はV3との表示比較を実施しました。

OBSでは、各表示方式とカード装飾・画面演出の併用、対話での配置保存、シーン切替後の停止・再開を確認してください。OBS側のシーン設定によってページ非表示通知の挙動が異なるため、Chromeの検証だけでは保証できません。

## 画面演出の追加

OBSのブラウザソースを再読み込みし、「画面演出」の選択肢から選びます。

| 演出 | 初期値と動き |
|---|---|
| Heart（ハート上昇） | 18個・80px・ピンク。画面内に出現し、揺れながら100px/秒で上昇して消える |
| Stars（流星） | 24個・48px・淡い金色。尾を伴い右下へ落下。縦方向300px/秒 |
| Sparkle（きらめき） | 24個・64px・淡い金色。画面内のランダムな位置で十字の光が時間差に輝き、膨らんでから縮んで消える |
| 紙吹雪 | 60片・16px・5色。画面内へ時間差で現れ、回転・横揺れしながら140px/秒で落ちる |

数・基本サイズ・色を各演出の設定で変更できます。Heart・Stars・紙吹雪は移動速度も調整できます。Sparkleはその場で輝き、時間は共通の「基準時間」で調整します。Starsは左下・右下・演出ごとのランダム方向を選べます。時間は共通の「基準時間」を使い、長くしても速度自体は変わりません。全体時間の途中で粒が出現・退場するため、全粒が指定時間ずっと残る意味ではありません。強度による増減後も上限は60個で、紙吹雪が60片設定の場合は強度を上げても数は増えません。

ブラウザで描画、固有値の保存、自然終了・全停止・待機取消・動き抑制、file起動を確認しました。画面演出はユーザー環境のOBSでも動作確認済みです。長時間負荷は継続確認中です。追加検証は node VCT_Stage_FX/tests/effects-browser.cjs で実行します。

ローカルサーバー運用のプロファイル適用もユーザー環境で確認済みです。

Sparkle追加（2026-09-16）：Chromeで描画・保存・停止・自然終了・file起動を検証。ユーザー環境のOBSでも動作確認済み。長時間負荷は継続確認中です。

配置編集のブラウザ検証：`node VCT_Stage_FX/tests/placement-browser.cjs`。ドラッグ・倍率・縮小表示・折りたたみ・取消・保存・タブ切替・全面表示での無効化を確認。2026-09-17にユーザー環境のOBSでもマウス操作を確認済みです。

# ROM爆弾 v0.1.0 確定仕様

わんコメのコメント受信を起点に、無言時間の経過後に爆弾を表示する配信演出テンプレート。VCT基盤のコメント正規化・設定保存・配置編集を利用する。

## 対象とライフサイクル

- 起動後の新しいリスナーコメントをサービスID＋ユーザーIDで管理する。配信者は除外。モデレーターは初期値で除外し、設定で対象に含める。
- 受信時刻からの無言時間で表示候補になり、最初に画面へ登場した時点から爆弾タイマーを開始する。初期値は表示待ち5分、登場後の警戒10分・危険15分・爆発20分。各値は正の分指定とし、登場後の警戒 < 危険 < 爆発だけを必須とする。表示待ちは独立し、警戒時間より長くてもよい。登場時は経過0／残り爆発設定値となる。通常は最後のコメントから合計25分で爆発する。
- 本人の再コメントで爆弾タイマーを解除し、表示待ちから再開する。表示中なら短い解除演出。再送ではリセット・解除を繰り返さない。
- 爆発開始時に監視データから削除する。再コメントは新しい世代として登録し、旧演出の終了で新世代を消さない。
- OFFは一時停止。停止中もコメントを受け取り、既存ユーザーはリセット、新規ユーザーは0で登録。停止期間は経過時間に含めない。
- ONのままOSスリープ等で更新が止まった場合は復帰時に経過時間を反映する。
- 期限切れ・重複履歴・演出データは掃除する。履歴を永続化しない。ページ再読込・わんコメのクリアで監視データを初期化する。
- 表示上限で待った人も初登場時から0で開始する。一度登場したサイクルは、その後枠外になっても時間を進める。未登場のままの人は表示待ち＋爆発設定時間で期限切れにする。表示待ち設定の変更で登場済みタイマーは巻き戻さず、登場後の条件変更は経過時間を保持して適用する。設定値の数値は既存値を保持し、意味を登場後基準へ更新する。

## 描画

- 1920×1080の透過キャンバス。縦横比を保ってプレビューに縮小する。
- 少し横長の132×62pxのミニカードに60×60pxのアイコンと💣。登場後のタイマーをアイコン下部に重ね、名前はカード外の下側。長い名前は132px幅で省略。
- 爆弾はアイコン横で脈動し、段階ごとの基準倍率1・1.45・2で成長する。アイコンとの重なりを許容。時間は爆弾より前面。カードの寸法・名前の位置を動かさない。
- 背景・発光で通常／オレンジ／赤の段階を表現。解除は✨、爆発は💥。効果音なし。
- ビジュアルモードはemoji（初期値）／visualを選択可能。emojiは従来の絵文字、visualはassets/visualの透過PNG爆弾・爆発を48pxの素材領域へ表示し、カードの縁取りを追加する。段階・脈動・時間・配置の処理は共通。解除は両方✨。読込中・読込失敗時は絵文字を表示し、古い読込結果を別状態へ適用しない。モードは表示プレビュー・取消・保存に対応。爆散はどちらのモードでも使用できる。
- カード爆散は初期値OFFの独立設定。爆発演出が有効な場合に、カード本体（アイコン・タイマー・背景）を6片のDOM複製として切り抜き、外へ飛ばしながら回転・フェードさせる。各破片の時間は爆発の残り時間と1.2秒の短い方。名前は650msでフェードし、爆発表示は従来の時間設定に従う。同じ爆発で再生成せず、アニメーション終了・カード削除・演出取消で破片を片付ける。canvas・外部依存は追加しない。
- 時間表示は登場からの経過時間（初期値）／爆発までの残り時間を選択可能。経過は秒切り捨て、残りは秒切り上げで0未満にしない。爆発中の残り時間は0。表示対象の順位は引き続き無言時間で決め、タイマーの経過とは分離する。停止再開は表示待ち・登場後の両方に適用する。表示方式はプレビューでき、閉じると未保存変更を取り消す。残り時間の計算は保存済み爆発条件に従う。
- 爆発から退場までの時間は0.3～30秒、初期値2秒。冒頭0.3秒で💥を拡大し、その後は倍率2.7～3の間を0.8秒周期で脈動させ、最後の0.3秒で💥・カード・名前をフェードアウトする。脈動は爆発絵文字のみに適用し、カード・名前・時間の位置は動かさない。最短0.3秒では拡大とフェードが同時進行し、脈動は行わない。時間は演出開始時に確定し、設定変更は次の爆発から適用する。演出OFF・本人の再コメントは既存どおり優先する。
- 無言時間の長い順に最大表示人数まで配置する。縦並び（初期値）は上から、横並びは左から。初期値10人、設定範囲1～30人。解除・爆発中も上限に含め、演出終了後に次候補を補充する。同率は登録順。
- カード間隔は名前を含む132×82pxの固定領域同士の余白とし、0～200px、初期値6px。縦は82px＋間隔、横は132px＋間隔で配置し、間隔にも全体倍率を適用する。末尾に余白は加えず、グループ全体を指定した四隅に固定する。縦の初期値のカード間隔は従来と同一。下端配置の末尾にあった6pxの空きはなくなり、指定オフセットで領域の下端が揃う。
- 折り返し人数は0～30の整数、初期値0で折り返しなし。縦並びでは1列の人数、横並びでは1行の人数を意味する。縦は上から下に詰めて右の列へ、横は左から右に詰めて下の行へ進む。必要な列・段を実際の表示人数から自動計算し、指定人数未満の余分な空き枠は作らない。末尾の半端な列・行はグループの上・左に詰める。4隅のプリセットはグループ全体の配置先を変更し、並ぶ順番は変えない。解除・爆発中も既存どおり表示人数に含め、退場後は空いた場所へ詰め直す。
- 枠外も設定した爆発時間で削除し、爆発演出は省略する。更新周期200ms、時間表示は秒単位。並び替えは220msの移動トランジション。
- 初期位置は右上、横20px・縦100px。4隅、オフセット、倍率（0.1～3）、名前・時間の表示、解除・爆発演出を設定できる。
- 設定UIの四隅選択は配置プリセットとし、選択時にOFFSET_X・OFFSET_YをCONFIG_DEFAULTの20px・100pxへ戻して1920×1080の選択した四隅へ配置する。倍率・並べ方・間隔・折り返しは変更しない。同じ選択肢へ戻すため「この四隅に戻す」を併設する。プレビュー・保存・取消は従来どおり。再読込・設定パネルの表示・設定ファイルの読込では保存済みのオフセットを維持する。
- 明示的なマウス編集モードで、グループ全体をドラッグ移動・ホイール拡縮できる。共通placement-editor v1を流用し、縮小プレビューの座標を1920×1080へ換算する。位置・倍率はスライダーと数値入力へ連動し、既存の保存・取消を使う。編集枠は人数が0でも1枚分を表示する。パネルを折りたたんでも編集を続けられるが、終了操作・保存・取消・ページ非表示で編集を終了し、編集状態は保存しない。
- 並べ方にランダム配置を追加。配置範囲はX・Y・幅・高さで指定し、画面内に収める。初期値は0・0・1920・1080、幅・高さは1px以上。各カードの中心を範囲内の一様乱数で独立抽選し、重なり・見切れの回避や再試行はしない。カード・名前・爆弾が指定範囲から出ることを許容し、ステージ境界でだけクリップする。
- ランダム座標は監視サイクルと対応付け、表示順位の変化や一時的な枠外移動では再抽選しない。解除後・爆発後の新しい監視サイクルでは再抽選する。範囲変更時は抽選済みの相対座標を維持する。実データとデモの座標を分離し、監視・演出のどちらからも消えたサイクルの座標を掃除する。座標は永続化しない。
- ランダム中のドラッグは範囲のX・Y、ホイールはカード全体の倍率を変更する。配置範囲の寸法は倍率で変えない。範囲の寸法はスライダー・数値入力で指定する。縦横の四隅・オフセット・折り返し・間隔は値を保持して設定UIでは非表示にし、縦横へ戻したとき再適用する。方式変更時はマウス編集を終了する。

## 受信と保存

VCT SDK 2.0.3-devを改変せず同梱。OneSDKの公開setup／subscribe／ready／connect／unsubscribeを既存方式で利用し、modeはdiff、permissionsはcomments・clear。公開CommentDataのID・役割・timestampとVCT正規化結果を利用する。ID・時刻の不足、起動前の履歴、システム通知等は登録しない。詳細な受信条件はREADMEを参照する。

設定はconfig_default.js→config.js→localStorage差分の順。V3.1のconfig-runtime・設定パネル・検証factoryを流用し、ROM爆弾用schemaと時刻順検証を追加。VCT Server連携・DBは使用しない。画像は安全なHTTP(S) URLだけを表示し、名前はtextContentで描画する。

監視・時間・人数・対象者・演出条件は保存時に適用し、既存データへ反映する。表示配置・並べ方・折り返し人数・間隔・名前・時間の表示は編集中にプレビューする。閉じると未保存の設定を取り消す。再読み込み不要の保存を基本とする。追加前の保存設定には新項目の初期値（折り返しなし等）だけを補い、既存値を維持する。

## 確認用表示と対象外

設定UIから別の監視エンジンでデモを実行する。表示待ち1.2秒、登場後の爆発4.8秒、保存済みの爆発演出時間、終了用の余裕0.4秒を合わせ、初期値で約9秒。デモの残り時間は短縮したテスト条件を基準にする。本番データ・設定には混入させず、終了・取消・保存時に確認表示を片付ける。確認表示中の本番データは受信を続けるが、未登場サイクルを裏で登場扱いにしない。本番表示へ戻した時点で期限処理と初登場を判定する。

効果音・TTS、ランキング、統計、配信をまたぐ履歴、サーバー、コマンド、ギフト特殊演出、個別ユーザー除外、個別カードのドラッグは対象外。画像素材はVisual modeの爆弾・爆発2点を含む。設定UIの既存の読込・保存機能は流用する。

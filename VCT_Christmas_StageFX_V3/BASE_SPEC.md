# VCT Stage FX v1.0.0 仕様

本書は継承元Stage FXの参照仕様です。クリスマス版の同梱内容と現在の仕様は[SPEC.md](SPEC.md)を参照してください。継承元に記載されたハロウィン演出はクリスマス版には同梱しません。

更新日：2026-09-17。製品バージョン：1.0.0（初回公開版）。

[初期版ドラフト](../__docs/VCT_Stage_FX/SPEC_DRAFT.md)を基準に実装した範囲と、具体化した挙動を記録する。利用方法・検証結果・制限は[README](README.md)を参照。本書と元テンプレートの仕様が異なる部分は、FXでは本書を正とする。

## 構成

- `runtime/`：Stage Base由来の1920×1080配置・レイヤー・演出実行／停止・Plugin登録。
- `adapters/`：OneSDK購読とVCT SDK正規化を一度だけ行う。表示設定の変更で再正規化しない。
- `widgets/comments/`：V3の共通カード・表示方式・カード装飾。`add / configure / clear / destroy`でStageへ接続し、購読は持たない。
- `main.js`、`triggers.js`：設定・入力・コメント表示・画面演出の接続と発火判定。
- `settings/`：タブUIとプロファイル別の設定保存。
- `effects/`：サークル・Halloween・Heart・Stars・紙吹雪・Sparkleの画面演出。カード装飾とは別系統。

新規3演出の数・サイズ・色・速度はFX_HEART_*／FX_STARS_*／FX_CONFETTI_*で保存する。カード装飾とは独立し、プロファイル別の表示設定へ含む。初期選択のサークルと既存の発火・待機・停止は変更しない。描画の仕様・再利用境界は[共有部品仕様](../__docs/VCT_Stage_FX/EFFECT_PORTING.md)を参照。長時間負荷は継続確認中。

Stage Base・View Comment V3・VCT共通正本には変更を加えない。SDKはV3同梱の2.0.4-devを使用する。既存のビルド不要・ローカルファイル運用を維持する。

## 配置と表示

ステージは1920×1080。containは全体を収め、coverは画面を埋める。レイヤーはBaseと同じ背景0、常設装飾10、コメント20、暗幕30、画面演出40、前景50。操作UIはステージの外側に置く。

コメント領域は1つ。初期配置はX80・Y100・幅760・高さ880・倍率1。Xは0～1920、Yは0～1080、幅は240～1920、高さは200～1080をスライダー5px刻み・数値入力1px刻み、全体倍率は0.5～1.5を0.05刻みで調整する。領域枠は初期OFF。

縦積みとポップアップ基準位置は指定コメント領域を使用する。全面ランダムとUnderbar（横流し・横積み）はステージ全面1920×1080・領域倍率1を使用する。指定領域の位置・幅・高さ・倍率は上書きせず、方式を戻すと元の値で再配置する。

カード・装飾は使用中領域の端でクリップする。縦積みでは20pxの余白を設ける。ポップアップとUnderbarでは余白を除く。拡縮で改行位置は変えない。

縦積み、ポップアップ、Underbar横流し・横積み、横流しの最大5レーンと振り分け方式は[V3仕様](../view_comment_V3/SPEC.md)を継承する。ポップアップ基準位置は指定領域、全面ランダムはステージ全体を基準とする。Underbarの幅・下位置はステージ全幅・下端が基準。横流しの速度はステージの論理px/秒で、ステージ倍率に応じて画面上の速度も拡縮する。指定コメント領域の倍率はUnderbarに適用しない。

Underbarの幅はtransform適用前のCSS寸法で計測し、ステージ・領域倍率を二重に掛けない。装飾の広がりは幅・レーン高さの計測へ含めない。横積みの画面外保持はV3同様に継続し、表示上は領域端で切る。

表示時間変更はV3同様に既存カードの表示開始時点から再計算する。表示方式の変更は残存カードを新方式に配置し、表示開始時刻を更新する。Underbarの設定プレビューでは残存カードを流し直す。取消で除去済みカードは復元しない。

正規化済み入力とコメントごとの装飾・配置乱数を保持し、表示設定変更では本文整形・配置だけを更新する。CSSの基本カード設定はコメントウィジェット内に限定する。

## 演出と動き抑制

Sparkleは画面内のランダムな位置に十字の光を時間差で出し、その場で膨らませてから縮小・消去する。FX_SPARKLE_COUNT（1～60、初期24）、FX_SPARKLE_SIZE（16～160px、初期64、2px刻み）、FX_SPARKLE_COLOR（初期#fff1b8）をプロファイル別に保存する。共通の基準時間・強度・停止管理を使い、カード装飾との組合せは固定しない。

カード装飾はV3のなし／ハート／Flash／Starsと対象条件を継承。初期は支援・メンバーにハート4個。画面演出は受信時に支援・メンバーを判定し、初期はサークル12個・3秒、同時1・待機6・queue。Underbarの登場には同期しない。

Baseのqueue／overlap／ignore、上限、強度判定、Plugin契約、受理済みパラメータの保持、最大実行時間、停止・破棄を継承する。詳細は[Base仕様](../VCT_Stage_Base/SPEC.md)と[演出制作ガイド](effects/README.md)を参照。

「画面演出を全停止」は単発演出の実行・待機を破棄する。常設への動作は後述の追加仕様に従う。「動き抑制」は画面演出とカード装飾を停止し、コメントの入退場・移動は継続する。OSの動き抑制には連動しない。動き抑制を解除すると残存カードの装飾は戻るが、停止した画面演出は復元しない。

入力clearはコメント・単発演出を消す。ページ非表示では新規入力を採用せず単発演出を破棄する。常設は後述の追加仕様に従って一時停止する。pagehideでは購読・表示タイマー・移動・演出・領域を破棄する。非表示前のコメント保持はBaseと同様で、再表示時に画面演出を発火し直さない。

## 設定UIと保存

ステージ／コメント配置／コメント表示／コメント装飾／画面演出／演出配置の6タブ。選択方式・装飾・画面演出に関係する項目を表示する。全面ランダムとUnderbarでは指定領域のX・Y・幅・高さ・倍率と配置ショートカットを無効表示にし、数値は保持する。基準位置・縦積みに戻すと再び操作できる。領域枠とUnderbar固有の下位置・カード倍率は引き続き操作できる。

全rangeに数値入力を付け、Enter・フォーカス移動で確定し、矢印キーと数値欄の上下ボタンで変更する。空欄・不正数値は直前値、範囲外・刻み外は各入力の範囲・刻みへ補正する。X・Y・幅・高さの数値欄は1px刻みで保持し、スライダーの5px目盛には丸め戻さない。

コメント配置タブから明示的にマウス編集を開始する。編集枠のドラッグはステージ表示倍率を補正してX・Yを1px刻みで更新し、枠内のホイールは領域倍率を0.05刻みで変更する。範囲は既存の数値入力と共通。空のコメント領域でも操作でき、設定パネルを折りたたんでも継続する。タブ切替・閉じる・ページ非表示で終了し、編集状態は保存しない。全面ランダム・Underbarでは無効。リサイズハンドルは実装しない。編集枠は確認用外枠の保存設定とは独立する。

全タブで同じ下書きを共有し、保存でまとめて確定する。タブ切替は設定を取消・保存しない。背景のクリックまたは×で閉じると起動時設定へ戻す。削除・停止済みの表示状態は戻さない。

設定は`config_default.js → config.js → localStorage差分`。コメント背景は`COMMENT_BG_COLOR`、ステージ背景は`BG_COLOR`とし、衝突を避ける。Google Fontsの新規通信は追加せず、端末のフォントを使用する。

HTTP(S)の`profile`はV3と同じ検証規則（半角英数字・ハイフン・アンダースコア1～64文字、大小文字区別）。fileは常にdefault。不正IDは警告してdefault。URLは起動時に解決する。

- 表示設定キー：`vct.stage-fx.settings.` + JSON形式の`[フォルダ名, プロファイルID]`。
- 演出登録一覧キー：`vct.stage-fx.effects.` + JSON形式のフォルダ名。プロファイルとは独立。
- 同じ保存環境の設定保存通知は同じプロファイルだけに届く。
- 演出登録一覧の変更は即時保存で、表示設定の保存・取消・削除とは独立。他画面は再読み込み時に反映する。
- 登録解除・ファイル欠落などで選択演出を読み込めない場合はサークルへ戻す。サークルも破損した場合はコメント表示を継続し、演出は再生できない。

プロファイル専用管理画面、履歴・待機状態の保存、Base・V3からの設定自動移行は設けない。

## 個別配置と常設演出の追加（2026-10-31）

製品番号は1.0.0のまま、クリスマス版の派生に先立つ基盤改修として追加する。3.1のコメントビューア、Stage Base、共通配置部品の正本は変更しない。

- 「演出配置」タブで登録済み演出を選び、個別のON/OFF・X/Y・幅/高さ・倍率・強度を設定する。配置対象の選択は編集用であり、イベント時に使う演出の選択とは独立する。演出配置タブの「演出を試す」は編集中の単発演出を対象にする。常設は個別ONで表示し、再開ボタンで動きを戻す。
- 演出領域はXが0～1920、Yが0～1080、幅が40～1920、高さが40～1080、倍率が0.1～3。位置・寸法はスライダー5px／直接入力1px、倍率は0.05／0.01刻み。ドラッグ移動・ホイール拡縮・縮小表示・折りたたみ・保存取消に共通配置部品を使う。コメント欄の既存範囲は変更しない。
- 幅・高さは演出のローカル描画領域、倍率は領域全体の拡縮である。領域の外側とステージの外側はクリップする。Context.sizeは倍率適用前の領域寸法。初期値はX/Yが0、1920×1080、倍率1で既存の全面演出を維持する。
- 個別強度は共通設定を使用／弱／標準／強／最大。大きさとは独立し、実際の粒数等はPluginが解釈する。単発演出のON/OFFは初期ON、常設は初期OFF。
- 保存キーは既存のフォルダー・プロファイル分離を維持し、設定項目に `STAGE_PLUGIN_<Plugin ID>_<ENABLED|X|Y|WIDTH|HEIGHT|SCALE|INTENSITY>` を追加する。IDは大小文字やハイフンも含めて保持する。この接頭辞は共通設定の予約領域。
- 既存の単発演出は選択された1種をイベント時に再生する。単発の同時実行数・待機・最大15秒は従来どおり。個別OFFにすると、その演出の実行中と待機中も取り消す。実行中の単発への配置変更は行わず、次回発火から適用する。
- `lifecycle: 'persistent'` の常設Pluginを追加できる。常設は背景とコメントの間に描画し、単発とは独立した最大4種類の枠を持つ。同じPluginの二重起動は拒否し、上限を超えた常設は起動しない。表示時間による強制終了は設けない。現時点の製品一覧へ常設の新演出は同梱しない。
- 常設は `update(params)` 必須。配置・強度・設定の変更時に同じインスタンスを更新する。個別OFF・登録解除・ページ破棄ではdestroyし、再度ONにした場合は新しいインスタンスになる。進行状態の永続保存は基盤に追加しない。
- 「画面演出を全停止」は単発の実行・待機を消し、常設は表示とインスタンスを保ったまま動きを一時停止する。「常設の動きを再開」で戻す。停止状態は保存せず、再読み込み時は設定に従って起動する。
- 「動き抑制」も常設表示を残して一時停止する。解除時は同じインスタンスを再開するが、全停止による一時停止が残っていれば停止を維持する。ページ非表示でも常設を一時停止し、再表示時に同じ状態から再開する。コメントのclearは従来どおりコメントと単発を消し、常設の状態は変えない。
- 共通の一時停止はContext管理のタイマー（残時間を保持）、Web Animations、CSSアニメーションを対象にする。独自のrequestAnimationFrame・外部タイマー・CSS transition等を使うPluginはparams.pausedを見て自身で停止・再開する。
- 「支援・メンバーで演出を再生」は従来どおり単発への設定。常設は各演出のON/OFFを使う。
- 同梱演出の追加設定は生成されたVCT共有契約にも含む。追加前の共有データは新項目だけ初期値で補完する。独自に追加した演出の設定・常設Pluginは従来どおりVCT共有対象外。

検証は `node --test VCT_Stage_FX/tests/*.test.cjs` と `node VCT_Stage_FX/tests/effect-placement-browser.cjs`。後者は一時HTTP配信の試験用常設Plugin2種を使い、製品一覧や実運用設定へ登録しない。Chromeでの模擬検証をOBS実機確認として扱わない。

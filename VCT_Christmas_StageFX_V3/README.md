# VCT Christmas Stage FX V3 · 0.1.0（開発版）

正式フォルダ名は`VCT_Christmas_StageFX_V3`です。V3はコメント表示基盤の世代、0.1.0はこの製品の開発バージョンを表します。OBSで試運転している開発元`VCT_Christmas_StageFX_dev`は参照先を保つため残し、同期先には正式名で配置します。設定・ツリーの成長はフォルダ名別のため、正式名のフォルダへ切り替えると新しい保存先になります。開発元のデータは残りますが、自動移行は行いません。

カードをクリスマス風にするには「コメント装飾 → 演出 → クリスマス（星・ベル・リボンが漂う）」を選びます。通常は星、支援はベル・リボンがカード全体をゆっくり漂い、淡く発光し続けます。小さな光も通常3個・支援6個が本文の上を通ります。新着時には通常0.9秒・支援1.4秒の強めの発光を一度だけ添えます。固定の角配置と動作中の特別な本文余白は廃止しました。既存のハート・Stars・Flashとは選択で切り替えます。動き抑制では右上の静止した飾りに戻し、生成素材なしでは同じ動きの絵文字へ切り替えます。初期の演出選択は変更していません。

「コメント配置」の「クリスマスの装飾枠を表示（領域に追従）」で、コメント欄全体を囲む枠を表示できます（初期OFF）。四隅はヒイラギと赤いリボン、辺は緑・金・赤の控えめな飾りです。コメントの移動・幅・高さ・倍率に追従し、枠の手動調整は不要です。「枠全体の背景色」と「枠の背景の不透明度」で台紙を調整できます。初期は透明、0で透明・1で不透明です。背景はコメントの後ろに描き、文字や角飾りの濃さは変えません。各コメントカードの背景設定とは別です。生成素材なしでも背景設定は使え、角は絵文字とCSSの枠に切り替わります。横流し・全面ランダムのように既存のコメント領域が全面になる方式では、枠も画面全体を囲みます。確認用の外枠とは別設定です。

個別配置・常設演出基盤を追加したVCT Stage FXを元にした、クリスマス版です。**生成ツリーが通常コメントと支援ポイントで成長するところまで実装済みです。**

OBSのブラウザソースを1920×1080で開き、右下の歯車から設定します。「演出配置」で演出ごとのON/OFF・位置・幅と高さ・倍率・強度を調整できます。ドラッグ移動とホイール拡縮に対応します。常設Pluginの動きは全停止で一時停止し、表示を保ちます。既存の単発演出を検証用に残しています。

設定はこのフォルダー専用で、Stage FXの保存値を変更しません。ローカルファイルで利用でき、Serverは不要です。VCT設定連携は無効です。Stage FXの共有枠へは接続しません。

「演出配置」でクリスマスツリーを選び、完成までの目標ポイントを設定します（初期500P、成長の細かさは10・20・30段階から選択、初期10段階）。通常コメントは1P、支援は基準ポイント×4段階の係数をボーナス加算します。基準は初期5Pで、ボーナスは5・10・15・25P。本文付き支援には通常分の1Pも加算します。基準を0にするとボーナスなしです。「成長を試す（保存しない）」で段階的に飾りが増え、完成後も1段階分ごとに強く発光する様子を確認できます。試した成長は保存せず、設定の取消・保存で実際の成長へ戻ります。実際の成長は再読み込み後も保持する設計で、手動リセットはパネル内で確認してから実行します。

「ステージ」の「クリスマス素材の表示」で生成素材なしへ切り替えると、ツリーと開封する箱はCSSと絵文字で表示し、背景画像も使用しません。

支援時はプレゼント箱が現れ、弾んでから開封し、光と飾りが広がります。「演出配置 → クリスマスのプレゼント開封」で配置・倍率・強度と「支援コメントで追加の開封演出を出す」（初期ON）を設定できます。ツリーに残るギフト飾りは従来どおりです。既存の単発演出とは同じ実行枠を使うため、順番待ち設定では順に表示します。開封自体を単発演出として選んだ場合は二重発動しません。自動追加だけを止める場合は専用チェックをOFF、開封をすべて止める場合は「この演出を有効にする」をOFFにします。「演出を試す」ではポイントを増やさず表示を確認できます。

「演出配置 → 配置する演出」で「クリスマスの雪」「クリスマスのイルミネーション」を選び、「常設表示を有効にする」で追加できます。初期はどちらもOFFです。雪は全面、電飾は上辺の1920×160を初期領域とし、それぞれ配置・倍率・強度を調整できます。電飾は暖かな金色とクリスマスカラーを選べます。全停止では表示を残して動きだけを止め、「常設の動きを再開」で続けます。両方ともCSS描画で、生成素材なしでも使えます。

段階飾りは赤い玉・金の玉・リボンの3種類を混ぜます。支援では別の小ぶりなベル・プレゼント箱が1個付き、段階が変わっても残ります。「ギフト飾りの上限数」は初期30個、1～120個に調整でき、数が増えると最低サイズまで縮小し、上限では古い順に押し出します。種類と位置は再読み込み後も保持します。上限を下げて保存すると古い飾りを整理します。支援ボーナス0でもギフト飾りは付きます。「ギフト飾りを試す（保存しない）」で確認できます。成長リセットはポイントとギフト飾りをまとめて戻します。

背景は「ステージ → 背景の種類」で、雪の森・暖炉の部屋・冬の夜空・透明を切り替えられます。中央を空けた絵本調の静止画で、切替によってツリーの配置や成長は変わりません。既存の背景色・画像を使う場合は「既存の背景設定（色・画像）」を選びます。初期値はこの既存設定を引き継ぐため、従来どおり初期状態は透明です。生成素材なしモードでは生成背景も表示しません。

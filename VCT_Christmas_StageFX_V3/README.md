# VCT Christmas Stage FX V3 · 0.1.0（開発版）

わんコメ・OBS向けのクリスマス配信テンプレートです。コメントと支援で育つツリー、雪・イルミネーション、プレゼント開封、コメント欄の装飾を組み合わせて使用できます。

フォルダ名は `VCT_Christmas_StageFX_V3`。V3はコメント表示基盤の世代、0.1.0は製品バージョンです。

## 使い始める

1. わんコメのカスタムテンプレートとして配置し、`index.html`をOBSのブラウザソースで開きます。
2. ブラウザソースの幅を1920、高さを1080にします。
3. OBSの「対話」で右下の歯車を押し、設定パネルを開きます。
4. コメントと演出を配置し、「変更を保存」で確定します。

ローカルファイルで使用でき、追加のローカルサーバーは不要です。VueとOneSDKは、わんコメが用意する隣接フォルダ `../__origin/js/` を参照します。

設定は変更中の見た目をプレビューします。×で閉じると未保存の変更を取り消します。ツリーの成長リセットと演出の登録操作は、その場で実行されます。

## 設定する場所

| タブ | 主な設定 |
| --- | --- |
| ステージ | 背景、生成素材／生成素材なしの切替 |
| コメント配置 | 位置・領域・倍率、クリスマス枠と台紙 |
| コメント表示 | 縦積み・ポップアップ・Underbar、文字やカードの表示 |
| コメント装飾 | ハート・Stars・Flash・クリスマスのカード演出 |
| 画面演出 | 支援時の単発演出、強度の決め方、基準時間、連続時の処理 |
| 演出配置 | ツリー・雪・電飾・開封など、各演出の有効化と配置・固有設定 |

コメントや各演出は、マウスでのドラッグ移動とホイール拡縮に対応します。X/Yは領域の左上、幅・高さは表示範囲です。プレゼント箱はその領域の中央付近に出るため、幅・高さを変えると出現位置も変わります。画面全体を使う場合はX/Yを0、幅1920・高さ1080にします。

## コメントで育つツリー

「演出配置」でクリスマスツリーを選びます。ツリーは初期ONです。

- 完成までの目標：初期500P。
- 成長の細かさ：10・20・30段階から選択。初期10段階。
- 通常コメント：1P。
- 支援ボーナス：基準ポイント×支援の4段階係数。基準は初期5P、係数は1・2・3・5です。
- 本文付き支援：ボーナスに本文分の1Pを加算します。基準0Pならボーナスを加算しません。

まず500Pで試し、完成までの時間を見て目標を調整してください。数回の配信にわたって育てる場合は、目標を多めに設定します。

完成形は共通で30個の段階飾りと頂上の星です。完成後も累計ポイントを保持し、目標の10％分が増えるたびに強く発光します。「幹の下に現在値／目標値を表示」でカウントを追加できます。

支援では段階飾りと別に、小さなベルまたはプレゼント箱が1個付きます。上限は初期30個、1～120個に調整でき、上限到達後は古い順に入れ替わります。上限を下げて保存すると、古い飾りが削除されます。支援ボーナス0でも飾りは付きます。

成長と飾りは再読み込み後も保存します。「ツリーの成長をリセット」は確認パネルで実行し、ポイントとギフト飾りをまとめて戻します。コメント欄のクリアでは成長をリセットしません。

「成長を試す」「ギフト飾りを試す」は表示確認用です。試験分は保存せず、「実際の成長に戻す」または設定の保存・取消で終了します。

## プレゼント開封

支援時に箱が現れ、弾んでから開封し、光と飾りが広がります。「演出配置 → クリスマスのプレゼント開封」で調整します。

| 基準値 | 初期値 |
| --- | --- |
| 時間 | 3000ms（画面演出の基準時間） |
| 箱サイズ | 268px |
| 飾りサイズ | 48px |
| 飛散距離 | 260px |
| 飾りの数 | 18個 |

基準値は独立して調整でき、演出全体の倍率でまとめて拡縮します。領域の外へ出た飾りは見切れます。

強度は次の優先順位です。

| 演出配置の強度 | 画面演出の設定 | 動作 |
| --- | --- | --- |
| 共通設定を使用 | 標準固定 | 基準値をそのまま使用 |
| 共通設定を使用 | 金額・件数に連動 | 支援の段階に応じて基準値へ係数を適用 |
| 弱・標準・強・最大 | どちらでも | 指定した段階の係数で固定 |

| 項目 | 弱 | 標準 | 強 | 最大 |
| --- | --- | --- | --- | --- |
| 時間 | ×0.85 | ×1 | ×1.15 | ×1.3 |
| 箱サイズ | ×0.9 | ×1 | ×1.15 | ×1.3 |
| 飾りサイズ | ×0.85 | ×1 | ×1.2 | ×1.4 |
| 飛散距離 | ×0.8 | ×1 | ×1.25 | ×1.5 |
| 飾りの数 | ×10/18 | ×1 | ×26/18 | ×34/18 |

個数は四捨五入します。基準18個なら10／18／26／34個、36個なら20／36／52／68個です。時間は係数適用後も最大10秒。4段階はテンプレート独自の分類で、配信サイトの公式色ランクとは異なります。

「支援コメントで追加の開封演出を出す」は初期ONです。OFFにすると追加発動を止めますが、使用する単発演出として開封を選んでいる場合は再生します。開封をすべて止めるには「この演出を有効にする」をOFFにします。

既存の単発演出と実行枠を共有し、「順番に待つ」では順に表示します。「上限まで重ねる」では設定した同時実行数まで併用します。ツリーに残るギフト飾りは、開封とは別に管理します。「演出を試す」でポイントを増やさず表示を確認できます。

## 背景・雪・イルミネーション

背景は「ステージ → 背景の種類」で、雪の森・暖炉の部屋・冬の夜空・透明・既存の色／画像設定から選びます。

雪とイルミネーションは「演出配置 → 配置する演出」から選び、「常設表示を有効にする」で表示します。初期は両方OFFです。それぞれ配置・領域・倍率・強度を調整でき、電飾は金色とクリスマスカラーを選べます。

## コメント欄の枠とカード演出

「コメント配置 → クリスマスの装飾枠を表示」で、ヒイラギとリボンの枠を追加できます。初期OFF。コメント領域の移動・幅・高さ・倍率へ追従します。

枠全体の背景色と不透明度も設定できます。初期は透明、0で透明・1で不透明です。背景だけがコメントの後ろに描かれ、文字や角飾りの濃さは変わりません。各コメントカードの背景設定とは独立しています。確認用の外枠とも別設定です。

カードは「コメント装飾 → 演出 → クリスマス（星・ベル・リボンが漂う）」で切り替えます。通常は星、支援はベル・リボンが淡く光りながらカード内を漂います。小さな光も本文の上を通過し、新着時は短い強めの発光を添えます。固定コメントとメンギフ受取通知は対象外です。

ポップアップの全面ランダムとUnderbarでは、コメント領域が画面全体になるため装飾枠も画面全体を囲みます。縦積み・ポップアップ基準位置では、設定したコメント領域を囲みます。

## 生成素材なし・動きの停止

「ステージ → クリスマス素材の表示 → 生成素材なし」で、ツリー・飾り・開封・カード装飾を絵文字やCSSへ切り替えます。生成背景は表示しません。進行ルールや保存データは共通です。

- 「画面演出を全停止」：実行中・待機中の単発演出を消し、常設演出は表示を残して動きを止めます。
- 「常設の動きを再開」：停止した常設演出を再開します。
- 「動き抑制」：画面演出とカード装飾の動きを抑えます。クリスマスカードは静止した飾りを表示します。コメント表示の移動は継続します。

停止中も、ツリーが有効でページ表示中ならポイント加算を続けます。ツリーOFF中・ページ非表示中は加算しません。

## 保存と制約

設定とツリーの成長は、フォルダ名ごとに保存します。フォルダ名を変えたり別のフォルダへ移したりすると、保存先が変わる場合があります。自動移行はありません。OBSと通常ブラウザの保存領域共有も前提にしていません。

既存のローカルサーバー経由で使用する場合は、URLの`profile`パラメーターで設定と成長を分けられます。ローカルファイル運用はdefaultプロファイルです。

開発版のため、初期値の調整と長時間運用の評価を継続しています。VCT Serverとの設定連携は無効です。

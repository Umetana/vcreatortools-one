# Halloween Parade Effect

作者製 `OBS Screen Effect V2` → `view_comment_Halloween_StageFX_V2_dev` から、MIT Licenseの範囲でロジック、CSS、画像素材を移植しています。このコピーはStage契約、強度設定、論理座標へ適合させたもので、OBS Screen Effectとの互換性を保証しません。

同梱PNGはDALL-E 3で生成した画像を元に分解、透過処理、Clip Studio Paint加工した素材です。再利用条件と免責はテンプレート直下の [README](../../README.md) と [LICENSE](../../LICENSE) に従います。絵文字モードではPNGを読み込みません。

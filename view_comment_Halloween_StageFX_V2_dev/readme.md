# View Comment Halloween StageFX V2 v0.1.0-dev

`View Comment Halloween V2 v0.1.0-beta.1` を安定版として残し、コメントイベント連動の画面演出を試すために分岐した開発版です。コメントビューアとしての機能を維持しながら、将来の `VCT_Stage_Base` に向けて演出をプラグイン単位で差し込める構造を検証します。

## 追加した画面演出

- スーパーチャット／スーパーステッカー: キャンディレイン
- メンバー加入／メンバーシップギフト: ゴーストナイト
- その他の支援イベント: ハロウィンパレード
- `emoji` / `image` の描画モード
- `queue` / `overlap` / `ignore` の実行方針
- 同時実行数、待機数、粒子数、継続時間、背景暗幕濃度の調整
- 軽量設定または画面演出OFF時の停止と実行中演出の破棄

通常コメントでは画面演出を開始しません。コメント表示、ギフト配色、背景、霧・浮遊装飾などの従来設定は派生元と同じです。

## 推奨OBS設定

ブラウザソースの幅を `1920`、高さを `1080` にします。異なるサイズでもステージはアスペクト比を保って拡大縮小されます。

画面右下のホットスポットから設定パネルを開けます。設定パネルは左右移動と折りたたみに対応しているため、コメント枠を右側へ置く場合も表示位置を確認できます。

## 画面演出の主な設定

- `ENABLE_STAGE_EFFECTS`: コメント連動画面演出のON/OFF
- `STAGE_EFFECT_INTENSITY_MODE`: `fixed`（標準固定）/ `value`（金額・件数連動）
- `STAGE_EFFECT_RENDER_MODE`: `emoji` / `image`
- `STAGE_EFFECT_POLICY`: `queue` / `overlap` / `ignore`
- `STAGE_EFFECT_MAX_ACTIVE`: 最大同時実行数
- `STAGE_EFFECT_QUEUE_LIMIT`: 待機キュー上限
- `STAGE_EFFECT_COUNT`: 基準粒子数
- `STAGE_EFFECT_DURATION_MS`: 基準継続時間
- `STAGE_EFFECT_BG_OPACITY`: 演出中の背景暗幕濃度

`image` モードでは同梱PNG素材を使います。`emoji` モードは画像を使わず、絵文字で同じ演出ロジックを確認できます。

`value` では金額または件数を小・標準・大・特大の4段階に分け、素材数、大きさ、継続時間、動き、暗幕を調整します。JPY、KRWと主要ドル・ユーロ・ポンド通貨に対応し、金額を判定できない通貨やイベントは標準強度になります。メンバーシップギフトは件数、ジュエルはジュエル数を使います。

## 確認方法

1. わんコメから通常コメントを流し、画面演出が始まらないことを確認します。
2. スーパーチャット、メンバー加入、メンバーシップギフトを流し、イベントごとの演出を確認します。
3. 描画モードと実行方針を変更し、保存・再読み込み後の挙動を確認します。
4. 連続送信時に設定した同時実行数と待機数を超えて蓄積しないことを確認します。
5. 軽量設定または画面演出をOFFにし、実行中の演出が消えることを確認します。

## 開発上の位置づけ

この版はStageFX基盤の実験を兼ねた開発版です。演出ホストAPI、汎用プラグインマニフェスト、外部プラグインの自動発見、演出設定UIの完全な共通化は今後の基盤化対象であり、現時点では実装していません。

確定仕様とイベント対応表は `SPEC.md`、内部構造は `TECHNICAL_SPEC.md` を参照してください。

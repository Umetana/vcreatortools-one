# View Comment Halloween StageFX V2 仕様書

## 1. 対象バージョン

- テンプレート: v0.1.0-dev
- 派生元: View Comment Halloween V2 v0.1.0-beta.1
- 参考基盤: OBS Screen Effect V2 / halloween_parade_effect
- 基準描画領域: 1920x1080

## 2. 目的

安定したハロウィンコメントビューアを保全したまま、コメントイベントと画面全体の演出を接続する実験版とする。ここで安定した汎用機能は、将来 `VCT_Stage_Base` へ抽出する。

## 3. 継承機能

- 通常コメント、ギフト、メンバー、固定コメントの表示
- 1920x1080ステージとコメント領域配置
- emoji / visual表示モード
- ギフト配色、背景、外枠、浮遊装飾、アイコンモード
- 設定パネル、ローカル保存、ライブプレビュー

## 4. StageFX v0.1範囲

- 画面演出専用レイヤーと任意暗幕
- Plugin単位のDOM、タイマー、Web Animations APIの一括破棄
- `halloween_parade_effect` の絵文字・画像素材モード
- ギフト・メンバーイベントからの自動発火
- 標準固定／金額・件数連動の演出強度モード
- `queue` / `overlap` / `ignore` の実行方針
- 同時実行数と待機上限
- 画面演出OFFまたは動き抑制時の即時停止
- ページ終了時の実行中・待機中演出破棄

## 5. イベント対応

| イベント | 演出パターン |
|---|---|
| スーパーチャット | キャンディレイン |
| Super Sticker / ジュエル | ランダムポップ |
| メンバー加入・継続 | ゴーストナイト |
| メンバーシップギフト送信 | ハロウィンパレード |
| メンバーシップギフト受取 | ランダムポップ |
| その他のサポートイベント | ハロウィンパレード |

通常コメントでは画面全体の演出を発火しない。

## 6. 演出強度

- `fixed`: イベントの金額や件数にかかわらず標準強度とする。
- `value`: 取得できた金額、メンバーシップギフト件数、ジュエル数を小・標準・大・特大へ分類する。

強度は素材数、大きさ、継続時間、動きの強さ、追加暗幕へ反映する。金額は通貨別のしきい値を用い、未対応通貨または値を取得できないイベントは標準強度へフォールバックする。演出パターン自体はイベント種別で決定し、強度判定では変更しない。

## 7. 実行方針

- `queue`: 上限到達時に到着順で待機する。待機上限を超えた新規演出は破棄する。
- `overlap`: 同時実行上限まで重ね、上限を超えた新規演出は破棄する。
- `ignore`: 何か実行中なら新規演出を破棄する。

既定値は `queue`、同時実行数1、待機上限6とする。再読み込み後に実行状態や待機列は復元しない。

## 8. Plugin境界

Pluginは `window.REGISTERED_EFFECTS[effectId]` へクラスを登録する。Hostは `EffectContext` を渡し、Pluginは `context.root`、`context.timers`、`context.animations`、`context.assets` を利用する。

CSSクラスはPlugin固有プレフィックスを使用する。外部入力をDOMへ出す場合は `textContent` を使用し、Plugin固有の外部イベントだけを `destroy()` で解除する。

## 9. 素材と流用元

`effects/halloween_parade_effect/` のロジックと画像素材は、同じ作者・MIT Licenseの `OBS_screen_effect_v2` から派生版へ移植している。画像素材を使用するPluginはAI生成素材であることを文書とManifestで明示する。

## 10. 初期段階の対象外

- ドラッグ式ステージエディタ
- 複数Pluginの動的読込UI
- 効果音
- 実行状態や待機列の永続化
- `VCT_Stage_Base` への抽出

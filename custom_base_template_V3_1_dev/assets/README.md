# 演出用の画像

ここへPNG・JPEG・WebP・GIF画像を置き、設定の「画像ファイル名」に `star.png` のように入力してください。サブフォルダは `stars/star.png` のように指定できます。外部URL・絶対パス・上位フォルダは指定できません。

初期値は絵文字モードです。画像モードへ切り替えるとファイル名欄が現れます。画像そのものはlocalStorageへ保存せず、ファイル名・モード・表示サイズだけを保存します。フォルダを配布する際は画像も含めてください。

表示サイズは画像の長辺を基準にしたpx指定です。縦横比を維持します。配布する画像には自作または利用許諾のある素材を使い、必要なライセンス表記を添えてください。

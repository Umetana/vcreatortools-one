# Custom Base Template V3 — 3.1.0-dev

3.1を今後の開発正本とします。3.0.0は旧版として残し、二重に改修しません。旧フォルダーと保存キーは分離し、自動移行しません。

AIエージェントと人間が、演出一つを組み込んだ単体コメントテンプレートを作るための開発ベースです。枠発光の最小サンプルを同梱しています。V2.8とは別フォルダで、既存版の設定移行は行いません。

## 使う
1. このフォルダをわんコメのカスタムテンプレートフォルダに置きます。
2. OBSブラウザソースへindex.htmlをローカルファイルとして追加し、幅1920・高さ1080を指定します。追加時の寸法指定は必要ですが、以後のコメント欄調整は内部で行います。
3. OBSの対話で右下の歯車を開き、位置・幅・高さ・倍率を調整します。幅は折り返し、倍率は文字と演出をまとめて拡縮します。
4. 「マウス配置の開始／終了」で編集枠をドラッグし、枠内のホイールで倍率を変更できます。幅・高さは数値入力です。設定パネルの折りたたみ中も配置できます。
5. 「通常を試す」「支援を試す」「メンバーを試す」で表示を確認します。模擬コメントは実コメントとは別の確認用です。
6. 「保存して再読み込み」で確定。閉じると設定を取り消します。消去済みのコメントは復元しません。

設定はconfig_default.js→config.js→localStorage差分の順。保存先はテンプレートフォルダ名で分かれます。別ブラウザとOBSの保存共有は前提にしません。ファイル読込は `window.CONFIG = {"COMMENT_X":80};` のようなJSON代入形式のみ対応します。専用の旧config_editor.htmlは継承せず、画面内パネルに統一しています。

コメント配置はスライダーと数値入力を併用できます。位置・寸法のスライダーは5px刻み、数値入力は1px刻み。倍率はスライダー0.05刻み、数値入力0.01刻みです。直接入力はEnterまたは欄を離れると確定し、入力途中には補正しません。空欄・不正値は直前の確定値へ戻り、範囲外は上下限へ補正します。範囲はXが0～1920、Yが0～1080、幅が160～1920、高さが80～1080、倍率が0.1～3です。

点線の編集枠がコメントの表示範囲です。コメントと枠演出はこの領域の外側を表示しません。長文などで境界にかかったカードは途中で見切れた状態で表示します。最大表示件数は保持上限として使い、高さを超えたことによるカード削除は行いません。最新1件だけで高さを超える場合も同じ扱いです。1920×1080の外側も描画されません。

## 作る

### 演出に画像を使う
素材対応の演出では「演出の素材」で絵文字／画像を切り替えられます。初期値は絵文字です。PNG・JPEG・WebP・GIF画像をassetsフォルダへ置き、画像モードの「画像ファイル名」に `star.png` などを入力してください。日本語・空白を含む名前や `stars/star.png` のようなサブフォルダも使用できます。

表示サイズは長辺のpx指定（1～512、初期32）。画像の縦横比を保持します。素材モード・ファイル名・サイズは他の設定と一緒に保存・取消できます。読込状況は素材プレビューへ表示し、失敗時は絵文字で表示します。画像データはlocalStorageへ保存しないため、配布時はassets内の画像も添えてください。

同梱の枠発光サンプルには、切替確認用の✨をカード右上へ追加しています。既存の素材非対応モジュールへ自動的に画像を追加することはありません。制作者が共通素材APIを使って対応します。

[開発ガイド](DEVELOPER_GUIDE.md)、[演出契約](PLUGIN_SPEC.md)、[仕様](SPEC.md)を参照してください。初期版に演出の自動検出・利用者による登録・複数演出切替・画面演出はありません。

## VCT設定連携（3.1.0-dev）

1. 更新済みVCT Serverを起動し、Electronの「ツール」→「わんコメテンプレート設定」、またはMain Serverの `/template-settings/` を通常ブラウザーで開きます。
2. 専用画面で表示・配置・演出の設定を編集し「VCTへ保存」します。保存先は1枠です。
3. 同画面の「テンプレートの接続設定」にあるURL・接続キーを、OBS対話の表示設定→「VCT設定連携（試験）」へ登録し「接続設定を保存」を押します。
4. 「VCTから読み込む」で検証・適用・localStorageへの保存を行います。未保存変更があればパネル内で破棄確認を行います。失敗時は現在の設定を維持します。
5. 起動時の方針は「ローカル設定で起動」（初期値）／「VCT設定を読み込んで起動」から選べます。後者はローカル設定で表示を開始して一度取得します。設定変更は次回起動・再読込から有効です。常時同期はしません。
6. 従来の「保存して再読み込み」は従来の場所でローカル保存を行います。「VCTへ保存」はローカル保存済みの値を送信します。編集中の値は送りません。VCT読込起動では再読込後に共有設定が適用されるため、上部の「変更を保存」→「VCTへ保存」なら再読込を挟まず送信できます。

他画面が共有設定を更新した場合は競合として送信を拒否します。必要な手元の変更を控えてから「VCTから読み込む」で取得し直してください。画像はassets内のファイル名だけを共有し、本体を転送しません。URL・キー・起動モード・パネル位置は端末固有です。

接続キーは設定連携専用であり、テンプレートのlocalStorageへ保存します。管理APIの認証ではありません。キーやローカル保存データを配布物に含めないでください。公式のこの3.1版・同梱glow演出を対応対象とし、フォークや演出差替えのVCT連携互換性は保証しません。派生版は別templateIdと専用の対応定義を用意してください。

利用者から、OBS 32.2.2（64bit）のローカルファイル、およびわんコメローカルサーバーのSource／DockでVCT連携が動作する報告を受領しました。Chrome fileの警告も現在は再現しないとの報告です。今回の保存操作・機能切替・定義整理後はChromeで検証し、OBSでの追加操作は未確認です。

## VCTを使わない運用と保存操作

`config.js` の `window.CONFIG` 内にある `VCT_LINK_ENABLED` を `false` にするか省略すると、VCTメニューと通信を無効にします。表示・演出・ローカル保存はそのまま利用できます。現在の試験用配布設定は `true` です。フラグはlocalStorageやVCT共有設定では上書きしません。古い接続キーやVCT起動モードが端末に残っていても、無効時は通信しません。

上部「変更を保存」は編集中の設定を検証してlocalStorageへ確定・即時適用します。UIを開いたまま再読込しません。「再読み込み」は未保存変更があればパネル内で確認します。下部の「保存して再読み込み」は維持します。VCT保存前に未保存変更がある場合は送信せず「変更を保存」を案内します。保存後にUIを閉じても新しい確定値を維持します。

## 起動時の表示とデバッグ設定

Vue初期化前のコメント領域を非表示にし、読み込み直後に未展開の文字や枠が一瞬表示されることを防ぎます。初期化後の配置・コメント表示は従来どおりです。

`DEBUG`（デバッグモード）は将来の診断用として項目と保存値を維持していますが、現状はオンにしても追加ログを出しません。起動時のReady、Vueの開発版案内、エラーはこの設定とは独立しています。

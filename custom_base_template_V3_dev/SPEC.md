# Custom Base Template V3 開発仕様

## 目的と初期範囲
版は3.0.0。AIエージェントと人間が、同梱資料を使って単体のコメント枠演出を制作するためのベース。
V2.8を元にコメント表示・設定保存を継承する。VCT Stage FXとView Comment V3は参考資料であり、設定・演出APIの互換性は設けない。

- 論理キャンバス1920×1080、OBSソースも1920×1080を指定する。小さいプレビューでは縦横比を保持して全体を縮小する。
- コメント領域は一つ。X/Y、幅/高さ、全体倍率を設定する。幅は折り返し、倍率は文字と装飾をまとめて拡縮する。
- コメントと枠演出は指定したコメント領域でクリップする。境界のカードは途中で見切れた状態を許容する。最大表示件数による保持を継続し、高さによる削除や最新1件の例外は設けない。キャンバス外もクリップする。
- 明示的な配置編集でドラッグ移動・ホイール倍率。幅・高さは数値入力。保存で確定、閉じると取消。
- 配置の5項目にスライダーと直接入力を併設する。位置・寸法はスライダー5px／直接入力1px、倍率は0.05／0.01刻み。直接入力はEnter・フォーカス離脱で確定し、入力途中は補正しない。空欄・不正値は直前確定値、範囲外は上下限に補正する。
- 演出は制作者が一つ組み込む。自動検出、利用者の登録、複数演出切替、画面演出は対象外。
- 演出固有設定は共通パネルに表示し、既存の設定差分保存を使う。
- 素材対応を宣言した演出は、絵文字（初期値）とassets内画像を共通UIで切り替える。画像ファイル名と表示サイズ（長辺1～512px、初期32px）をlocalStorageへ保存する。画像モード時だけファイル名欄を表示し、読込失敗は設定UIへ表示して既定絵文字に戻す。素材の配置と動きは演出モジュールが担当する。
- 通常・支援・メンバーの模擬コメントと消去を提供する。

## 構造
main.jsとindex.htmlはコメント表示、runtime/は固定キャンバスと演出契約、effect-entry.jsは制作者が選ぶ一つのモジュール、effects/は演出実装、settings/は共通設定UI。
VCT SDK 2.0.3-devを継承。SDKの版とテンプレートの版は別管理。実受信は公開OneSDKの既存連携を継承し、新規APIは追加しない。

## 検証方針
模擬入力で表示・演出対象・削除・設定取消・配置・保存を確認する。実際のOBS対話と実受信は別途確認が必要。模擬確認を実機確認と扱わない。

# View Comment V3 v3.0.0 詳細仕様

基本の導入・操作は[README](readme.md)を参照してください。本書は配布版の現行仕様です。

## 動作と構成

製品版は3.0.0。同梱VCT SDKは2.0.4-devで、版番号を別管理します。OneSDKからのコメントを同梱SDKで正規化し、共通カードへ表示します。VueとOneSDKはわんコメが用意する隣接の`../__origin/js/`を参照します。わんコメ本体・Vue・OneSDKをZIPには同梱しません。ローカルサーバーは通常利用には不要です。

フォントはGoogle FontsのM PLUS 1pを読み込み、取得できない場合は指定の代替フォントを使います。OS・フォントによってカード幅が変わります。描画領域はOBSソースの幅・高さに追従し、領域外の描画は切れます。

## 共通カード・演出

名前・アイコン・バッジ・本文・翻訳・支援／メンバー通知を共通設定で表示します。通知の情報量はわんコメと配信サイトから届くデータによります。翻訳は受信済みの翻訳を表示する機能で、テンプレート自身による翻訳生成はしません。

演出は「なし／ハート／Flash／Stars」から1種類を選びます。表示方式とは独立しています。演出対象は支援のみ／支援＋メンバー／すべてから選択します。ハート・Starsの初期対象には固定のみのコメントを含めません。

### ハート

出現・成長しながら上昇し、回転して消える動きを繰り返します。初期6個・32px・ピンク・周期2.5秒。基本サイズに対して±30％の個体差があり、動きによる拡縮も加わります。本文より手前や枠外にも重なります。

### Stars

カード上方から星が斜めに降り、回転・拡大・明滅・色相変化を伴って消えます。初期12粒・14～28px・周期1.8～3.2秒。右下／左下／コメントごとにランダムの方向を選べます。同一コメントの星は同じ方向へ降ります。色は6桁HEXのカンマ区切り。不正色は除外し、全て不正なら初期色に戻します。サイズ・周期の最大が最小を下回る場合は最小に揃えます。

### Flash

枠発光を基礎に次の見せ方を選べます。初期はShimmer、金色、強さ0.75、周期3秒です。

| 見せ方 | 動き |
|---|---|
| 枠の発光 | 枠の光のみ |
| Shimmer | 幅広い白い光の帯が横切る |
| Glint | 右上付近の大小の光がきらめく |
| Trace | 角丸の縁を光が一周する |
| Halo | 枠の内外で柔らかい光が揺らぐ |
| Aurora | カード背景の明暗グラデーションと色相が動く |
| Sweep | 細い白い線が素早く横切って休止する |
| ランダム | 上記7種類からコメントごとに抽選 |

指定色／コメント強調色連動を選択可能。枠・発光が連動し、光の芯や帯は白を維持します。Traceの周期は一周の時間です。Auroraでは設定3秒に対して背景移動は往復16秒、色相は往復24秒で、設定値に比例します。旧保存値`aurora`はHalo、`aurora-background`は背景型Auroraを表します。

配置・個体差・Flash抽選はコメントごとに保持します。設定プレビューや演出を切り替えて戻した場合も保持し、ページ再読み込みでは作り直します。clear・退場で装飾も除去します。

## 表示方式

### 縦積み

初期表示。最大8件、幅900px、上方向へ積み上げ、間隔4px。自動非表示は初期0（時間では消さない）。最大件数を超える古いコメントは除去します。表示時間を変更した場合は表示開始時刻から再計算します。

### ポップアップ表示

「表示方式」で縦積み／ポップアップを選びます。縦積みが初期値です。ポップアップは新着を待たせず、縮小・軽い回転から膨らんで収まる動きで出現させます。短文生成はせず、受信コメントを共通カードで表示します。ハート・Flash・Starsは表示方式とは独立して選べます。

- 全面ランダム: ソース全域からカード中心の位置を抽選。見切れ・重なりを許容します。
- 基準位置＋ばらつき: 基準X/Y（0～100％）から左右・上下の指定幅（各±0～100％）内へ配置。幅0なら同じ位置へ重なります。画面内へ押し戻しません。
- カード幅: 160～1200px、初期420px。倍率適用前の折り返し幅です。
- 基本倍率: 25～200％、初期100％。枠・文字・アイコン・バッジ・装飾を一緒に拡縮し、倍率変更では改行位置を変えません。
- 表示時間: 1～30秒、初期6秒。時間経過後に約0.48秒かけてフェードアウトします。
- 最大同時表示数: 1～50件、初期12件。新着を手前へ重ね、上限超過では最古から退場。退場中のカードは短時間残るため、DOM数は設定上限を一時的に超えます。

基準位置はソース描画エリアの左上を原点に、横は左から・縦は上からの割合で指定します。横0％は左端、100％は右端、縦0％は上端、100％は下端です。指定点はカードの中心で、ばらつき設定によりその周辺へずれます。横50％・縦50％で中央です。基準位置の初期値は中央、ばらつきは左右±8％・上下±6％。位置と倍率をプレビューしても配置乱数は維持します。ソース寸法変更では配置が同比率で追従し、カード幅はpxのままです。全面で使う場合はOBSでブラウザソースを画面いっぱいに設定してください。長文は共通の本文上限・折り返し設定に従います。

表示方式の切り替え時は残っているコメントを新方式に並べ直し、その時点から表示時間を計り直します。幅・倍率・配置・色などの調整では寿命を延長しません。表示時間の変更は表示開始時点から再計算するため、短くすると即退場する場合があります。取消では設定と配置を戻しますが、既に時間切れや上限超過で消えたコメントは復元しません。保存・再読み込み後はコメントを作り直します。

ポップアップでは専用の表示時間・同時表示上限を使い、縦積みの最大表示件数・自動非表示・積み上げ方向は適用しません。配置・寿命の処理をdisplay/に分離し、clear・上限除去・破棄でタイマーを解除します。縦積みでも自動非表示時間のプレビューは表示開始時点から再計算します。

### Underbar（横流し）

「表示方式 → Underbar」で、ソース下部へカードを流します。初期は一段です。通常・支援・メンバー・固定とも同じ列へ流し、専用の優先レーンは設けません。カードの外観と装飾は共通設定を使用します。

| 設定 | 初期値・範囲 |
|---|---|
| 方向 | 右から左。左から右へも切替可能 |
| 移動速度 | 140px/秒、30～600px/秒。ソース幅や倍率を変えても速度自体は同じ |
| カード最大幅 | 600px、180～1200px。倍率適用前、最小幅180px。内容に応じて可変 |
| カード全体倍率 | 100％、25～200％。文字・アイコン・装飾も含めて拡縮 |
| 下端からの位置 | 28px、0～500px。倍率後のカード下端からソース下端まで |
| カード間隔 | 60px、0～300px。倍率に依存しない描画上の最小間隔 |
| 待機上限 | 20件、1～100件。超過時は古い待機を除去して新着を優先 |

本文は一行に省略し、翻訳併記時は原文・翻訳が各一行になります。名前等のヘッダーも一行で表示し、幅を超えた部分は省略・クリップします。高さは内容と共通の文字・アイコン設定に従います。本文内スクロールは未実装です。

発車直前にカードの幅を計測し、その幅を走行中は固定します。前のカードの実寸と間隔をもとに発車待ちを入れ、同じ速度で流します。画面外へ抜けたカードから除去します。縦積み・ポップアップの表示時間や最大表示数は使用しません。待機上限は走行中を含まないため、全カード数とは異なります。低速で待機が多い場合は新着表示が遅れるため、速度や待機上限を調整してください。

設定プレビューでは残っているカードを入口から流し直します。閉じると保存前の設定で再配置しますが、既に退場・破棄したコメントは復元しません。方式変更・clear・ページ破棄で移動と待機を解除します。ソース幅変更時も走行中のカードは同速度で進み、新しい発車位置と退場判定は現在のソース幅を使用します。

枠外のハート・Stars・Halo等はカード間に広がるため、必要に応じて間隔と下位置を調整してください。間隔計算はカード本体を対象とし、装飾の広がりを含みません。

### Underbarの横積み

Underbar設定の「Underbarの表示」で横流し／横積みを切り替えます。初期は従来の横流しを維持します。横積みでは右から左なら新着を右端へ、左から右なら新着を左端へ入れ、既存カードを新着の実寸幅＋間隔だけ押し出します。ソース内側20pxを新着の停止位置とします。

時間による自動削除は行いません。新着がない間は停止したまま残します。古いカード全体がソース外へ出て、さらに「画面外の保持余裕」を超えた時点で除去します。保持余裕は最大カード幅×倍率×指定枚数で、初期2枚分、0～4枚分を0.5刻みで調整できます。例えば最大幅800px・倍率100％・2枚なら、画面外へさらに1600px押し出すまで保持します。可変幅のため枚数は実際のコメント件数を意味しません。

スライド時間は初期450ms、0～2000ms。移動中に新着が来ても現在位置から次の目標へ進み、出発位置へ戻しません。除去したカードの分を詰め直さず、残ったカードの位置を維持します。

方向・最大幅・倍率・下位置・間隔は横流しと共用。横流し専用の速度・待機上限は横積みに適用しません。本文の一行省略や装飾も共用します。設定プレビュー・取消では残存カードを新しい設定で並べ直します。clear・方式切替・破棄で移動を解除します。

### 横流しの複数レーン

「レーン数（横流しのみ）」で1～5段（初期1段）、「上下の間隔」で0～200px（初期20px）を設定できます。最下段は共通の下端位置から始まり、上方向へ増えます。横積みには適用しません。

空き優先では各レーンの入口でカード実寸幅と横間隔を確認し、空いたレーンから待機順に発車します。同時に空いていれば下段を優先します。待機上限は全レーン合計です。方向と速度は全段共通です。

段の高さは受信カードの実測高さ×倍率に合わせ、上下間隔は倍率適用後のpxです。高い通知が来た場合は上段を押し上げ、通知が退場しても段の高さを縮めません。設定変更・方式切替・clearによる再配置で高さをリセットします。ソース上端を超える配置は見切れます。Stars・Halo等の枠外装飾は段の高さに含めず、上下間隔で調整してください。

### レーンの振り分け

（横流しのみ）

- 空き優先（初期値）: 入口が空いたレーンへ発車し、同時に空いていれば下段を優先。ゆっくりした受信では下段だけを使う場合があります。
- 順番: 受け付け順に下→上→下と巡回。受信間隔が長くても指定した全段を使います。
- ランダム: コメントごとに指定段数から一度だけ抽選。同じ段が連続する場合もあります。

順番・ランダムは割り当て先の入口が空くまで待機し、待機中に割り当てを変えません。他段は独立して発車するため、画面へ出る順番は受信順と前後する場合があります。待機上限は全段合計で、超過時は従来どおり古い待機を除去します。設定変更・clearなどの再配置で振り分けもやり直し、順番は下段から再開します。

## 設定の保存とプレビュー

設定の優先順は`config_default.js → config.js → ローカル保存差分`。配布用config.jsは空です。初期設定へ戻した場合も保存操作が必要です。画面内設定はプレビュー、保存で再読み込み、閉じると未保存値を取り消します。消えたコメントを取消で復元することはありません。

各設定スライダーには数値入力欄があります。Enter・フォーカス移動で確定、上下ボタン・↑↓で既存の刻みごとに変更します。空欄・不正値は直前値へ戻し、範囲と刻みを補正します。色選択ポップアップ内のHSLスライダーと設定ファイルエディタは別の操作体系です。

フォルダ名で保存領域を分けます。HTTP運用では`?profile=talk`のようなプロファイルIDも使用可能です。半角英数字・ハイフン・アンダースコアの1～64文字、大文字小文字を区別。省略・空欄はdefault、不正IDは警告付きでdefault。ローカルファイルでは常にdefaultです。異なるブラウザ間の設定共有、コメント履歴の同期、旧派生からの自動設定移行は行いません。

config.jsは全プロファイル共通の基準値です。config_editor.htmlで作成できます。OBSのローカル保存差分がある項目はそちらが優先されるため、ファイル更新が見えない場合は画面内設定の保存元も確認してください。

## 制限と確認範囲

Underbarの本文内スクロール・複数行折り返し、Stageとの統合、外部Plugin管理は提供しません。操作UIは右下の歯車方式です。装飾の広がりはカード間隔の計測に含みません。

WindowsのOBSで各表示方式・演出・数値入力をユーザーが確認済み。ブラウザー自動検証はOneSDK受信境界を模擬しています。全配信サイト・全通知・長時間負荷・全OSの動作を保証するものではありません。確認環境はOBS Studio 32.2.2（64bit）、わんコメ9.2.0-alpha18です。

# 変更履歴

## 3.1.0

- ギフトカードを通常ログとは別に画面内へ配置。
- スパチャ・ステッカー・ジュエル・メンバーシップギフト送信／受取・その他ギフトを個別選択。
- 左下の歯車／Alt＋Shift＋Eで配置編集。ドラッグ移動・個別削除。
- 内容・位置・重なり順を自動保存し、再読み込み後に復元。
- 設定パネル内で確認して全消去。標準ダイアログは使用しません。
- 既存利用では配置機能は初期OFF、対象はスパチャのみON。通常ログの動作を維持。
- 旧設定ファイルエディタを含めず、2026-09-30の安全な設定読込対応を継承。

## 3.0.0

初回公開版。

- 縦積み・ポップアップ・Underbar横流し／横積み。
- 横流しは1～5レーン、空き優先・順番・ランダムの振り分け。
- ハート・Stars・Flash（7種類＋ランダム）。
- 画面内設定、即時プレビュー、保存・取消、数値入力による微調整。
- フォルダ別保存とHTTPプロファイル、設定ファイルエディタ。
- VCT SDK 2.0.4-dev同梱。


## セキュリティ対応（2026-09-30）

旧 `config_editor.html` は削除し、画面内設定パネルを使用します。ファイル読込ではJavaScriptを実行せず、`window.CONFIG = {...};` または `window.CONFIG_FILE = {...};` の値だけを解析します。コメント、末尾カンマ、引用符なしのキー、文字列・数値・真偽値・null・配列・オブジェクトに対応します。関数呼出しや式、複数の代入は使用できません。配布更新時は以前の `config_editor.html` が残っていれば削除してください。

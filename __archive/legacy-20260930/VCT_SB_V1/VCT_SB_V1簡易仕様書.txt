VCT SB V1(旧VCT Support Banner)

簡易仕様書 v1.0.0dev

1. 概要

VCT_Core が形成した支援イベントのうち、対象 streamId の支援だけを横スクロールカードで表示する OBS 向けテンプレート。
表示テンプレ本体はDB保存責務を持たず、Core DBを読む表示専用テンプレートとして扱う。

2. 目的

- 支援コメントを見やすく常時表示する
- `VCT_Core` が形成した `supports` を見やすく表示する
- 表示テンプレと保存基盤の責務を分離する
- 将来の VCT 系表示テンプレートの read-only 実装サンプルにする

3. 表示対象

- 支援付きコメントのみをカード表示する
- 通常コメントは表示しない
- 通常コメントの `users` 更新は `VCT_Core` が担当する

4. 表示構成

- 上段: タイトル帯
- 下段: 支援カード列の横スクロール

各カードの主な内容:
- ユーザーアイコン
- ユーザー名
- 支援額または件数
- コメント本文

表示位置:
- OBS ソース内の表示領域を `startX` / `startY` / `endX` で指定する
- カードはその表示領域の右端から入り、左方向へ流れる
- 今回は `endY` は持たず、縦位置は `startY` 基準の固定

5. スクロール仕様

- カード列を横方向に連続スクロール
- 末尾まで流れたらループ
- スクロール速度、カード幅、カード間隔、表示件数は設定で変更可能
- 少数件でもループが破綻しにくいよう、内部的に表示セットを複製して連結する

カード色モード:
- `soft`: ギフト色ベースで背景になじみやすいグラデーション
- `contrast`: より見出し感のある強めグラデーション

カード色の不透明度:
- ギフト色そのものの不透明度を調整する
- 背景とのなじませを優先したい場合に使う

6. データ参照仕様

参照先は IndexedDB `vct_common_data` DB。

使用ストア:
- `supports`: 支援イベント履歴
- `users`: ユーザー現在値。ただし本体表示では直接使わない

本体の参照方針:
- 起動時: `VCT_IDB.getSupports({ streamId, limit, order })` で表示対象を読む
- 支援イベント受信時: 表示用レコードを形成して画面へ即時追加する
- DB保存: 行わない。`VCT_Core` が担当する
- DB削除: 行わない。`VCT_Core` または `VCT_SB_V1_UI` が担当する

7. 設定仕様

設定解決順:
1. `localStorage`
2. `config.js`
3. 本体内デフォルト値

初回起動時に保存済み設定がなければ、`config.js` ベースの値を `localStorage` へ保存する。

主な設定項目:
- `title`
- `startX`
- `startY`
- `endX`
- `streamId`
- `limit`
- `displayOrder`
- `maxMessageLength`
- `showIcon`
- `titleVisible`
- `titleHeight`
- `amountVisible`
- `messageVisible`
- `viewportHeight`
- `cardWidth`
- `cardGap`
- `scrollSpeed`
- `cardColorMode`
- `cardBackgroundOpacity`
- `emptyStateText`
- `resetStreamOnLoad` (互換用。V1本体では削除に使わない)
- `resetAllOnLoad` (互換用。V1本体では削除に使わない)

8. 管理UI

本体とは別に `VCT_SB_V1_UI` を持つ。

dashboard の役割:
- `supports` / `users` の閲覧
- 検索 / 集計 / 削除
- 本体設定の読込 / 保存 / 初期化
- 保存前プレビューで表示位置や見え方を確認

設定変更は dashboard 側で行い、本体ブラウザソースの再読み込みで反映する運用を前提とする。

9. エラー時の基本方針

- OneSDK 未読込時はコンソールへエラー出力
- IndexedDB 初期化失敗時は起動失敗として扱う
- アイコン取得失敗時は画像なしで表示継続
- 支援データ 0 件時は `emptyStateText` を表示

10. 現時点の位置づけ

- VCT_Core 前提の支援表示テンプレート
- `vct_common_data.supports` の read-only 表示サンプル
- `v1.0.0dev` 段階の配布候補
- 保存責務を Core に寄せた次世代版として扱う

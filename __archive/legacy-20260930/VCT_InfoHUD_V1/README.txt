VCT_InfoHUD_V1
Version: v0.9.8-dev

概要

VCT_InfoHUD_V1 は、OBS配信向けの下部固定型情報HUDです。
わんコメコメント、同接、高評価、告知テキストを 1920 x 1080 固定レイアウトの下部バーに統合表示します。

このテンプレートは、コメントビューアではなく「配信情報HUD」として使うことを想定しています。

対象環境

- OBS Studio
- わんコメ
- OBS Browser Source
- 解像度 1920 x 1080

使い方

1. わんコメのカスタムテンプレートとして、このフォルダを配置します。
2. OBSの Browser Source で index.html を表示します。
3. Browser Source の幅と高さを 1920 x 1080 にします。
4. OBS側で上部の設定UIをクロップし、下部HUDだけを配信画面に表示します。

設定UI

設定項目は以下のタブで切り替えます。

- 基本
- 数値
- ログ
- ビジュアル
- 文字
- 情報文

設定UIで変更した内容は「現在の設定を保存」から localStorage に保存されます。
読込元の指定は「読込元設定を保存」から保存します。
ログタブの「本文言語」で、YouTube自動翻訳があるコメントを元文または翻訳文として表示できます。

OBSでカラーピッカーが使えない場合は、HEX入力欄に #ffffff 形式で色を入力してください。

読込元

自動：
保存済み設定 > config.js > 初期設定

保存済み設定：
localStorage > config.js > 初期設定

config.js：
config.js > localStorage > 初期設定

初期設定：
内蔵初期設定

主な機能

- 下部固定HUD
- わんコメコメント表示
- 同接/高評価表示
- 同接/高評価エリアの標準/上部空きスロット切り替え
- わんコメ meta による同接/高評価取得
- 手動値とmeta値の切り替え
- 情報テキストの自動切替
- ギフトカードのINFOエリア一時表示
- イベント本文表示の種別別切り替え
- ギフトカード表示内容の切り替え
- localStorage保存
- config.js読込
- 読込元指定
- ビジュアル調整
- HUD本体背景の単色/2色グラデーション切り替え
- フォント/文字サイズ/文字色調整
- 画像絵文字/YouTubeスタンプのインライン表示

備考

通常コメントは白文字で表示します。
スパチャ、メンバーシップ、ギフト系コメントは、取得できた色を行背景に反映します。
支援金額は本文に混ぜず、初期設定ではログ行内のバッジとして表示します。
メンバーシップギフトは [メンギフ x5]、ギフト受け取りは [ギフト受取] のように表示します。
チャンネルオーナーコメントには小さな OWNER バッジを表示します。
モデレーターコメントには小さな MOD バッジを表示します。
情報ウインドウは、複数行のテキストを一定間隔で切り替えてループ表示します。
ギフトカードを有効にすると、支援系コメント受信時に情報ウインドウを一時的に差し替えて表示します。
初期設定では無効です。
メタ項目名、メタ数値、通常ログ文字、INFO文字は設定UIから色を変更できます。
HUD本体背景は、従来の単色に加えて2色グラデーションを選択できます。
多色、虹グラデーション、アニメーション背景は初期対象外です。
同接・高評価は、手動値またはわんコメ meta データを表示できます。
初期設定では、meta データが来た場合はmeta、来ない場合は手動値を表示します。
メタエリアを「上部空きスロット」にすると、同接・高評価を下段に圧縮し、上段をOBS側で時計や画像などを重ねるための空きスペースとして使えます。
「2x2スロット」では上段を左右2つの空きスロット、下段を同接・高評価として使えます。
ログの表示行数は、HUD高さ、ログ行高さ、ログ行間、コメント文字サイズの組み合わせで調整できます。
画像絵文字とYouTubeスタンプは、コメント本文内の位置にインライン表示します。

# view comment heart V2 v2.0.0-dev

わんコメ用の「Glassmorphism（グラスモーフィズム）」と「ハート演出（Heart Embrace）」を特徴としたカスタムテンプレートです。
背景のぼかしと、コメントに重なるようにふわふわと浮かぶハートで、可愛らしくも高級感のある画面演出を提供します。

V2 は VCT SDK v1.2.6-dev の `parseStructured()` / `event` レイヤーへ移行した新方式版です。
スパチャ、Super Sticker、メンバーシップ、メンギフ送信/受取をSDK側の分類に基づいて表示します。

## 主な機能

- **Glassmorphism デザイン**: 背景をぼかした半透明のコメント枠で、どんな背景にも馴染みます。
- **ハート演出 (Heart Embrace)**: コメントの周りをハートが舞う演出。ギフト時のみ、または常時表示を選択可能。
- **柔軟なカスタマイズ**: `config_editor.html` を通じて、エディタで直感的に設定を変更できます。
- **積み上げ方向の切り替え**: 上から下、または下から上へコメントを積み上げることができます。
- **ギフト・スパチャ対応**: ギフトやスパチャ時には、枠線や背景にアクセントカラーが適用されます。
- **メンバー強調対応**: メンバー系コメントの背景・枠線濃度を個別に調整できます。
- **イベント分類対応**: `parsed.event` を参照し、メンバーシップ加入やメンギフ受取をギフト表示と分離します。
- **ユーザー属性バッジ対応**: 配信者には OWNER、モデレーターには MOD バッジを表示できます。
- **イベント本文フィルター**: スパチャ、ステッカー、メンバーシップ、メンギフなどの本文表示を種別ごとに切り替えできます。
- **YouTube自動翻訳対応**: `COMMENT_TRANSLATION_MODE` で元文、翻訳文、両方表示を切り替えできます。

## 設定項目（主なもの）

- **表示方向**: コメントが下から上に増えるか、上から下に増えるかを選択。
- **ハート設定**:
  - モード: `off`（なし）/ `gift`（ギフト時のみ）/ `always`（常時）
  - 数・サイズ・色: 舞うハートの数や大きさ、色を調整可能。
- **タイマー**: 一定時間後にコメントを自動で消去する設定が可能（0で永続表示）。
- **フォント・サイズ**: お好みのフォントや基本文字サイズに変更可能。
- **イベント本文**: `SHOW_EVENT_MESSAGES` と `SHOW_EVENT_MESSAGE_*` で、イベント種別ごとの本文表示を制御可能。
- **翻訳表示**: `COMMENT_TRANSLATION_MODE` で `original` / `translated` / `both` を選択可能。

## 導入方法

1. わんコメの「テンプレート」フォルダを開きます。
2. `view_comment_heart_v2` フォルダをそのままコピーして配置します。
3. わんコメの「テンプレート選択」から `view_comment_heart_v2` を選択します。

## 設定エディタについて

`config_editor.html` は設定値の編集と `config.js` の生成に使えます。
ブラウザのセキュリティ制限により、直接読み込み・上書き保存が使えない場合は、`config.jsをダウンロード` で生成したファイルをテンプレートフォルダ内の `config.js` と入れ替えてください。

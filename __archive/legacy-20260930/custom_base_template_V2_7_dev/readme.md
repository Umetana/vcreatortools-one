# Custom Base Template V2.7 v2.7.2-dev

VCT SDK (`vct_one_core.js`) v1.2.6-dev に対応した、わんコメ用カスタムテンプレートの試験ベースです。

V2.7では、画面内設定パネルとlocalStorage設定を試験導入しています。従来版の `custom_base_template_V2` は変更せず残しています。

V2世代のコメント表示テンプレートを元に、固有演出を外し、コメント表示・イベント分類・設定エディタ・VCT SDK 同梱構成を新規テンプレート開発へ流用しやすい形に整理しています。

## 主な機能

- Vue 3 + OneSDK によるコメント購読
- VCT SDK v1.2.6-dev の `parseStructured()` 対応
- 通常コメント、スパチャ、Super Sticker、メンバーシップ、メンギフ送信/受取、固定コメントの基本表示
- ユーザー名、アイコン、バッジ、OWNER/MOD、イベントラベル、本文パーツの分離表示
- ギフト/メンバー系コメント枠の背景・枠線濃度調整
- イベント種別ごとの本文表示フィルター
- YouTube自動翻訳文の試験表示モード
- `config_editor.html` による `config.js` 編集
- 右下ギアから開く画面内設定パネル
- localStorageによる設定差分の保存
- 設定編集中のライブプレビュー
- 背景・枠線・影の一括透明化プリセット
- 旧 `VCT.parse()` への最低限のフォールバック

## 画面内設定パネル

画面右下の透明なホットスポットへマウスを重ねるとギアが表示されます。ギアをクリックすると、設定パネル本体とCSSを遅延読み込みします。

設定の適用順:

1. `config_default.js`
2. `config.js`
3. localStorageに保存された変更差分

後の設定ほど優先されます。パネルで保存すると再読み込みされ、localStorage設定が適用されます。
保存キーはテンプレートフォルダ名から生成されるため、別名でフォークしたテンプレートとは設定が分離されます。

パネルでは次の操作ができます。

- 現在の適用値をフォームへ読み込む
- `config.js` の値をフォームへ読み込む
- 初期設定をフォームへ読み込む
- 任意の `config.js` ファイルをフォームへ読み込む
- localStorageへ保存して再読み込みする
- localStorage設定を削除し、次回から `config.js` を使う
- 背景・枠線・影をまとめて透明化する

設定を変更すると、保存前でも画面へ一時的にプレビューされます。パネルを閉じると未保存変更は破棄され、起動時の設定へ戻ります。
設定を保存または削除した場合は、BroadcastChannel APIで同じテンプレートを開いている別画面へ再読み込み通知を送ります。これにより、ローカルサーバー運用時は設定ドック側で保存した変更を、表示用ブラウザソースへ反映しやすくなります。

その場で確認しやすい項目:

- 背景、通常枠線、ギフト/メンバー/固定コメント枠線
- ぼかし、影、文字色、フォントサイズ
- 表示幅、コメント間隔、積み上げ方向
- アイコン、名前、バッジなどの表示切り替え

本文上限、イベント本文フィルター、自動非表示タイマーなど、コメント受信時に決まる項目は、新しいコメントまたは保存後の再読み込みで完全に反映されます。

背景画像を別ソースで重ねる場合は、`背景・枠を透明` を起点に調整できます。個別設定では `BG_GLASS` を透明色にし、`BASE_BORDER_OPACITY`、ギフト/メンバー濃度、`SYSTEM_BORDER_OPACITY` を `0` にします。

OBSではブラウザソースの「対話」を開いた状態で操作してください。

### URLパラメーターによる設定UI起動

ローカルサーバーで運用する場合、URLに `?settings=1` を付けると起動時に設定パネルを自動で開けます。

```text
表示用:
http://localhost:8080/custom_base_template_V2_7_dev/index.html

設定ドック用:
http://localhost:8080/custom_base_template_V2_7_dev/index.html?settings=1
```

OBSのブラウザソースには通常URLを使い、カスタムブラウザドックには `?settings=1` 付きURLを使うと、表示画面へ設定UIを出さずに調整できます。
このURLパラメーターは設定UIを開くトリガーだけで、設定値の読み込み順や保存内容は変更しません。
設定ドックで保存またはローカル設定を削除すると、同じローカルサーバー上で開いている表示用URLにも再読み込み通知が送られます。`localhost` と `127.0.0.1` のようにホスト名が違うURL同士では別オリジン扱いになり、通知は届きません。

## 使い方

1. `custom_base_template_V2_7_dev` フォルダをコピーして、新しいテンプレート名に変更します。
2. `template.json` の `name` / `description` を変更します。
3. `index.html` / `main.js` / `style.css` を元に、固有の見た目や演出を追加します。
4. 設定項目を増やす場合は、`config.js` / `config_default.js` / `config_editor.html` / `settings/settings-schema.js` を合わせて更新します。

## 開発メモ

- コメント本文は `parsed.message.parts` を優先して表示します。
- `COMMENT_TRANSLATION_MODE` で元文、翻訳文、両方表示を切り替えます。
- 金額、メンバーシップ、固定コメントなどの情報は `parsed.event` / `parsed.system` からメタラベルへ分離します。
- CSS カスタムプロパティは `main.js` の `updateStyle()` で `window.CONFIG` から反映します。
- `lib/vct_one_core.js` はこのテンプレートに同梱しています。共有化する場合は `index.html` の読み込みパスを調整してください。

## 設定エディタについて

`config_editor.html` は従来どおり設定値の編集と `config.js` の生成に使えます。
わんコメのカスタムテンプレート置き場やブラウザのセキュリティ制限により、直接読み込み・上書き保存が使えない場合があります。
その場合は `config.jsをダウンロード` で生成したファイルを、テンプレートフォルダ内の `config.js` と入れ替えてください。

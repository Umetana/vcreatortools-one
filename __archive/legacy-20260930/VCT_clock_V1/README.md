# 🕒 OBS用 クロップカスタマイズ時計 (VCT-CLOCK) v1.0.0

OBS Studioなどの配信ソフトでの利用に特化した、高機能なカスタマイズUI付きのデジタル時計Webツールです。

配信画面上での見栄えをリアルタイムに調整できる「調整コンソール」と「時計表示部」を1画面に同居させ、OBSのクロップ（切り抜き）機能を用いて時計部のみを配置・運用する設計となっています。

---

## ✨ 主な機能と特徴

1. **4つの公式デザインプリセット内蔵**
   - **サイバー・ネオン**: 近未来デジタル風、蛍光色に強いグロー効果。
   - **ミニマル・モダン**: 細身のゴシック体、白文字に半透明の黒背景。
   - **レトロ・ポップ**: 丸みのあるフォント、パステルカラーに太い黒フチ取り、コロン点滅。
   - **シック・和モダン**: 美しい明朝体、落ち着いた金色の文字に縦書き風「午前/午後」添え字表記。

2. **OBSブラウザソース互換仕様（重要）**
   - **テキスト入力式カラー選択**: OBS Studioの相互作用ウィンドウ内で動作しないことがあるカラーピッカー対策として、カラーコード（HEX）を直接キーボードで入力・編集できる入力欄を完備。
   - **ボタングループ式フォント選択**: OBS内で展開できないことのあるドロップダウンメニュー（`<select>`）の代わりに、実際の書体プレビュー付きのグリッドボタンを採用。

3. **誤表示を防ぐスマートガイド機能**
   - クロップ位置を視認しやすくするための「ガイド枠（点線）」は、**画面上にマウスカーソルが乗っている間（OBSの「相互作用」ウィンドウでの操作中など）のみ自動で表示**されます。配信画面上では自動的に非表示となるため、枠線の消し忘れによる放送事故を防ぎます。

4. **マイプリセット保存（3スロット）**
   - ユーザーが作成したお気に入りのスタイルを、名前（例：「APEX用」「朝雑談」など）をつけて最大3つまで保存・復元できます。

5. **自動状態ロード（ラストステート維持）**
   - 最後に保存された状態がブラウザの `localStorage` に自動的に保存され、OBS起動時やリロード時に自動適用されます。

## 🚀 OBS Studioへの配置・設定手順

### 1. ブラウザソースとして追加
1. OBSの「ソース」パネルの `+` ボタンから **「ブラウザ」** を新規追加します。
2. **「ローカルファイル」** にチェックを入れ、本フォルダの `index.html` を選択します。
3. 幅を `1920`、高さを `1080` （フルHDサイズ）に設定します。

### 2. デザインの調整と保存
1. OBSソース内の「ブラウザソース」を右クリックし、**「相互作用」** を選択します。
2. 操作画面（設定コンソール）が開くので、プリセットを選択するか、スライダーやカラー入力等で好みのデザインに微調整します。
3. 調整が完了したら、右上の **「💾 設定を完全に保存」** をクリックします。
4. 相互作用ウィンドウを閉じます。

### 3. クロップ（切り抜き）して配置
1. 画面左上（`0,0` 位置）に配置されている **340px × 120px** の時計表示エリアを確認します。
2. OBSプレビュー上で、キーボードの **`Alt` キーを押しながら** ソースのバウンディングボックスの四辺をドラッグし、時計表示エリア（ガイド枠の範囲内）だけが残るように切り抜きます。
3. 切り抜いた時計ソースを、配信画面の好きな位置に配置すれば設定完了です！

## 🛠️ パラメーター設定一覧

| 設定項目 | 説明 |
| --- | --- |
| **フォントスタイル** | 5種類（デジタル/和風レトロ/ポップ/モダン/シック明朝）から選択。 |
| **時刻の文字サイズ** | スライダーで24px〜72pxに調整可能。 |
| **文字の間隔** | 文字と文字の間（レタースペーシング）を-5px〜10pxで調整。 |
| **各種カラー** | 文字色、光彩（ネオン）色、背景色をピッカーまたはHEXコード（例: `#00FFCC`）で設定可能。 |
| **発光強度** | 文字の発光（グロー）の広がりをスライダー調整。 |
| **背景の透明度** | 時計の背景座布団の不透明度（0%〜100%）を設定。 |
| **時計枠の丸み** | 背景座布団の角丸の強さ（0px〜40px）を設定。 |
| **表示スイッチ群** | 秒表示 / 日付表示 / 24時間表記（OFFで午前/午後） / コロン点滅 / 文字の黒縁取りのON/OFF。 |

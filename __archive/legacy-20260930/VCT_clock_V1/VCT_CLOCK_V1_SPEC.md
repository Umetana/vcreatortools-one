# 📋 OBS用 カスタマイズクロップ時計：製品仕様書 VCT-CLOCK v1.0.0

## 1. 概要

本プロジェクトは、OBS Studioなどの配信ソフトでの利用に特化した、HTML/CSS/JSで動作するWebベースのデジタル時計ツールである。
配信画面上での見栄えをリアルタイムに調整できる「高機能設定UI（コンソール）」と「時計表示部（プレビュー）」を1画面に同居させ、OBSのクロップ（切り抜き）機能を用いて時計部のみを配置・運用する設計とする。

---

## 2. 画面レイアウト・構成

画面全体の解像度は **1920px × 1080px（フルHD）** とし、内部を2つのエリアに完全分離する。

* **時計プレビューエリア（表示部）**
  * **サイズ:** 縦 120px × 横 340px
  * **配置:** 画面の左上（`Top-Left`）に固定配置。
  * **スマートガイド枠:** 設定UI動作中（キャンバスにマウスがホバーしている状態）のみ、OBS側でのクロップ作業を容易にするための薄い「切り抜き境界線（点線）」を表示する。配信時（非ホバー状態）は自動的に非表示となり、誤表示を防止する。

* **設定UIエリア（コントロール部）**
  * **サイズ:** 1920px × 940px（画面上部 140px 以降の全スペース）。
  * **役割:** 各種パラメーターの調整、プリセットの選択、保存管理を行う。

---

## 3. 機能仕様

### ① リアルタイム・カスタマイズ機能
UIの操作（スライダー、カラーコードテキスト入力、カラーピッカー、チェックボックス等）が、即座に時計表示部のCSS変数へ反映され、見た目がリアルタイムに更新される。

### ② 公式デザインプリセット（4種）
ベースデザインとして以下の4パターンをデフォルトで内蔵する。
各プリセットを選択すると、設定UIの各パラメータが自動的に該当数値へ書き換わり、そこからさらにユーザーによる微調整（カスタム）が可能。

| プリセット名 | 想定フォントスタイル | カラー／装飾特徴 | 表示レイアウト |
| --- | --- | --- | --- |
| **1. サイバー・ネオン** | `Share Tech Mono` (デジタル風) | 蛍光色（シアン `#00ffcc`）／強い光彩（`text-shadow`） | `12:34:56`（1列大きく、日付非表示） |
| **2. ミニマル・モダン** | `M PLUS 1p` (ゴシック) | 白文字／背景に薄い黒の半透明座布団（不透明度60%） | 上段：日付、下段：時刻（2段） |
| **3. レトロ・ポップ** | `M PLUS Rounded 1c` (丸ゴシック) | ピンク `#ff79c6` ／太めの黒フチ取り（`text-stroke`）／コロン点滅 | 1列コンパクト（日付非表示） |
| **4. シック・和モダン** | `Sawarabi Mincho` (明朝) | ゴールド系 `#e5c158` ／落ち着いた余白感／和風デザイン | `午前/午後` 添え字表記（日本語） |

### ③ 運用時の状態自動ロード（ラスト状態保持）
OBS起動時（ブラウザソース読み込み時）、またはリロード時は、`localStorage` から「最後に保存された状態」を自動で読み込み適用する。

### ④ カスタム保存スロット（マイプリセット機能）
* ユーザー自身がカスタマイズした設定値を、公式プリセットとは別に最大3つまでブラウザに保存できる。
* **名前変更機能:** 各スロットには「APEX用」「朝の雑談」など、自由なテキストを入力して管理できる。
* スロット呼び出し時、および保存完了時には、設定値とUIの状態が即座に同期される。

### ⑤ OBS互換性向上（特化仕様）
* **ボタングループ式フォント選択:** OBSの「相互作用」ウィンドウで機能しないことが多いドロップダウン（`select`）を廃止し、フォントファミリーを直接切り替えるボタングループを採用。
* **双方向連動テキストカラー入力:** カラーピッカー（`input type="color"`）がOBS内部で展開できない場合があるため、HEXカラーコード（例: `#FFFFFF`）を直接キーボードで入力・修正できるテキストボックスをカラーピッカーの横に配置。

## 4. 技術要件 ＆ 内部データ構造

* **使用技術:** HTML5 / CSS3（CSS変数の活用、Tailwind CSSによるUI装飾） / JavaScript (Vanilla JS、外部JSライブラリ不使用)
* **データ保存先:** ブラウザの `localStorage`
* **ガタつき防止:** 数字のフォント幅の違いによる時計全体の横揺れ（振動）を防ぐため、CSSの `font-variant-numeric: tabular-nums;` を適用。
* **設定保持用データ構造 (JSON):**
  ```json
  {
    "fontFamily": "'Share Tech Mono', monospace",
    "fontSize": "48px",
    "fontColor": "#00ffcc",
    "glowColor": "#00ffcc",
    "glowRadius": "10px",
    "bgColorRaw": "#000000",
    "bgOpacity": "40",
    "borderRadius": "8px",
    "letterSpacing": "0px",
    "showSeconds": true,
    "showDate": true,
    "use24h": true,
    "blinkColon": true,
    "guideToggle": true,
    "useOutline": false
  }
  ```

## 5. CSS変数（カスタムプロパティ）設計

時計の表示スタイリングは、以下のCSS変数を書き換えることで動作する。

| CSS変数 | 対応パラメータ | デフォルト値 |
| --- | --- | --- |
| `--clock-font-family` | フォントスタイル | `'Share Tech Mono', monospace` |
| `--clock-font-size` | 時刻の文字サイズ | `48px` |
| `--clock-font-color` | 文字カラー | `#00ffcc` |
| `--clock-bg-color` | 背景カラーおよび不透明度の合成 (rgba形式) | `rgba(0, 0, 0, 0.40)` |
| `--clock-glow-color` | 文字光彩のカラー | `rgba(0, 255, 204, 0.8)` |
| `--clock-glow-radius` | 文字の発光強度 | `10px` |
| `--clock-border-color` | クロップガイド線の色 | `rgba(255, 255, 255, 0.2)` |
| `--clock-border-width` | ガイド線の太さ | `1px` |
| `--clock-border-radius` | 時計枠の丸み (角丸) | `8px` |
| `--clock-letter-spacing` | 文字の間隔 | `0px` |
| `--clock-text-stroke` | 時計文字のフチ取りスタイル (黒フチなど) | `0px transparent` |
| `--clock-text-stroke-date` | 日付文字のフチ取りスタイル (比率調整) | `0px transparent` |

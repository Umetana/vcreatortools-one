# VCT Comment Roulette V1 v0.1.0

わんコメのコメントをトリガーに、コメントしたリスナーを対象としてルーレット抽選を行うカスタムテンプレートです。

候補一覧を先に表示し、選択枠が一覧を高速巡回して徐々に減速します。結果には実質的な成績やポイントを持たせず、配信中の雑談やコメント欄の反応を作る演出として使用します。

## 使い方

1. わんコメでこのテンプレートを追加します。
2. コメント欄へ `!ルーレット` または `!roulette` と投稿します。
3. 投稿者名、ランダムテーマ、1〜12件の候補が表示され、抽選が始まります。
4. 結果は右側の履歴へ追加されます。

演出中に届いた新しい起動コマンドは無視します。履歴はlocalStorageへ保存されるため、OBSやブラウザソースを再読み込みしても復元されます。

履歴を消去する場合は、わんコメのクリア操作か、画面内設定パネルの `履歴を消去` を使用します。

## 辞書の編集

候補は `dictionaries.js` にあります。各辞書は次の形式です。

```js
themeKey: {
  title: "テーマ名",
  items: ["候補1", "候補2", "候補3"]
}
```

テーマや候補は自由に追加・削除できます。候補数より表示枠数が多い場合は、一巡するまで重複させず、その後に再シャッフルして補充します。

## 設定

主な設定は `config.js`、全初期値は `config_default.js` にあります。OBSのブラウザソースで対話を開き、右下のギアから画面内設定も利用できます。

- `TRIGGER_COMMANDS`: 起動コマンド。カンマ区切り
- `AUTO_TRIGGER`: 通常コメントから自動起動するか
- `AUTO_TRIGGER_RATE`: コメント1件あたりの自動起動確率
- `MIN_SLOTS` / `MAX_SLOTS`: 表示枠数。実行時に1〜12へ制限されます
- `SPIN_DURATION_MS`: 選択枠の巡回時間
- `RESULT_DISPLAY_MS`: 結果表示時間
- `HISTORY_MAX`: 履歴の最大件数

履歴は設定とは別のlocalStorageキーへ保存され、常に `HISTORY_MAX` 件以内へ切り詰められます。

コマンドは前後の空白を除いたコメント全文と、大文字小文字を区別せず比較します。文中にコマンドを含むだけでは起動しません。

## ファイル構成

- `index.html`: 画面構造とスクリプト読込
- `style.css`: レイアウトと演出
- `main.js`: コメント受信、抽選、巡回、履歴管理
- `dictionaries.js`: テーマと候補
- `config.js`: 利用者設定
- `config_default.js`: 全設定の初期値
- `lib/`: VCT SDK
- `settings/`: 画面内設定パネル

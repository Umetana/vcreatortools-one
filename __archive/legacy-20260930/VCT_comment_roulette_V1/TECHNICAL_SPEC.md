# VCT Comment Roulette V1 Technical Spec

## 構成

- UI: Vue 3 Composition API
- コメント受信: OneSDK `comments`
- コメント解析: VCT SDK `parseStructured()`、旧版では `parse()` へフォールバック
- 永続化: localStorageへ直近の結果履歴を保存

## 履歴保存

履歴はテンプレートフォルダ名から生成した専用キーへJSON配列として保存します。

```text
vct.comment-roulette.history.<template-id>.v1
```

起動時に各エントリを検証して復元し、`HISTORY_MAX` 件以内へ切り詰めます。抽選結果追加時、わんコメのクリア操作、設定パネルの `履歴を消去` 操作でlocalStorageと表示を同期します。設定保存用キーとは分離されています。

## 起動判定

`parsed.message.text` をtrimし、小文字化した値を `TRIGGER_COMMANDS` と完全一致比較します。自動起動は通常コメントだけを対象とし、確率判定とグローバルクールダウンを通過した場合に起動します。

演出開始から結果表示終了までは `running` で排他し、その間の追加起動を無視します。コメントIDは直近500件まで記録して重複処理を防ぎます。

## 抽選

1. 有効な辞書からテーマをランダム選択
2. `MIN_SLOTS`〜`MAX_SLOTS` の範囲で枠数を決定
3. 候補をシャッフルして枠を構築
4. 当選位置を先に決定
5. 候補一覧を表示
6. 選択枠を最低巡回数だけ動かし、三次曲線で待ち時間を増やして減速
7. 事前決定した位置へ停止
8. 結果と履歴を表示

候補が不足する場合は、シャッフル済み候補を一巡ごとに追加します。1枠の場合は確定演出として、その枠を選択したまま指定時間待機します。

## 状態

- `idle`: 待機画面
- `intro`: 候補一覧を表示
- `spinning`: 選択枠を巡回
- `result`: 当選枠と結果を強調

設定プレビューイベントでは色とフォントを即時反映します。抽選条件やタイマーは次回起動から反映されます。

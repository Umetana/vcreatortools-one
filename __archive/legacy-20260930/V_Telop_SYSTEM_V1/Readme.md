# V-Telop System V1 v1.0.7-dev

わんコメのカスタムテンプレートとして使える、配信用テロップ表示システムです。

トークテーマや告知文を登録して手動または自動で切り替えられます。v1.0.7-dev では、わんコメのギフト系コメントを受け取り、通常テロップ枠を一時的にギフトカード表示へ切り替える割り込み演出を追加しています。

## 主な機能

- 3つのテロッププリセット管理
- 1行1項目のテロップ登録
- 手動送り、戻し、番号ジャンプ
- Auto Rotation による自動送り
- 表示ON/OFF切り替え
- フォント、色、透明度、縁取り、背景、アクセント線、位置、フレーム画像の調整
- `frames/*.png` を使ったフレーム付きテロップ表示
- わんコメ OneSDK からのコメント購読
- ギフトコメントのキュー管理とランク別表示時間
- ギフトカード倍率の調整
- 表示専用モードと補助表示HTML

## ファイル構成

- `index.html`: わんコメカスタムテンプレート用の本体です。設定、操作、表示モード、ギフト割り込み処理を含みます。
- `v_telop_display_v1.html`: OBSなどへ直接追加するための補助表示HTMLです。
- `v_telop_system_v1.html`: v1.0.6 系の一体型HTMLです。互換・参照用として残しています。
- `css/vtelop-common.css`: 通常テロップとギフトカードの共通スタイルです。
- `frames/`: テロップフレーム画像です。

## 使い方

1. わんコメのカスタムテンプレートとして `V_Telop_SYSTEM_V1` フォルダを配置します。
2. わんコメまたはブラウザで `index.html` を開きます。
3. `ジェネレーター` で表示したいテロップを1行ずつ登録します。
4. `設定` で見た目、表示位置、フレーム、ギフト割り込み設定を調整します。
5. `操作パネル` で On-Air プリセット、表示ON/OFF、送り/戻し、Auto Rotation を操作します。
6. 配信用には `表示専用へ` を押すか、URLに `?mode=display` を付けて表示専用モードを使います。

表示専用モードから戻る場合は `Ctrl + Shift + D` または `Escape` を使います。

## ギフト割り込み

`設定` の `Gift Interrupt` でギフト割り込みを調整できます。

- 初期状態では `command_only` です。ギフトコメント内に `!jack`、`!sponsor`、`!支援`、`!スポンサー` などの VCT コマンドがある場合に割り込みます。
- 発動モードを `all` にすると、検出できたギフト系イベントをすべて割り込み対象にします。
- キュー上限、Low/Mid/High の表示秒数を設定できます。
- 金額ランクの初期値は Low: 1円以上、Mid: 1000円以上、High: 5000円以上です。

この版は dev 版です。ギフトカードの見た目、mixed content、通貨差によるランク判定は今後調整される可能性があります。

## ホットキー

操作パネルまたは表示専用モードで使えます。入力欄へフォーカスしている間は無効です。

| キー | 動作 |
| --- | --- |
| `N`, `Space`, `ArrowRight`, `+` | 次のテロップへ進む |
| `P`, `ArrowLeft`, `-` | 前のテロップへ戻る |
| `V`, `*` | 表示ON/OFF |
| `A` | Auto Rotation ON/OFF |
| `1` - `9` | 指定番号のテロップへジャンプ |
| `0` | 10番目のテロップへジャンプ |
| `Ctrl + Shift + D` | 表示専用モードの切り替え |
| `Escape` | 表示専用モードから戻る |

## OBSで使う場合

基本は `index.html?mode=display` をブラウザソースとして追加する運用を推奨します。

`v_telop_display_v1.html` は補助表示用です。本体表示モードと完全に同一の見え方を保証するものではありません。サイズ感や位置に差が出る場合は、本体の表示専用モードを基準に調整してください。

## 注意事項

- 設定とテロップデータはブラウザの `localStorage` に保存されます。
- ブラウザやOBSソースを変えると、保存済みデータが共有されない場合があります。
- `index.html` は `../__origin/js/onesdk.js` と `../_vct_core/js/vct_one_core.js` を読み込みます。フォルダ構成を変える場合は読み込みパスに注意してください。
- `v_telop_display_v1.html` はギフト割り込みの現在状態を `localStorage` と `BroadcastChannel` から追従します。

VCT SB V1 UI

簡易仕様書 v1.0.0dev

1. 概要

`VCT_Core` が形成した IndexedDB と、`VCT_SB_V1` の localStorage 設定を閲覧・管理するための管理テンプレート。
OBS 内部ブラウザでも扱いやすいことを優先し、詳細は画面内パネルで表示する。

2. 目的

- 支援履歴を一覧で確認する
- ユーザー現在値を確認する
- 通貨別集計や支援回数を確認する
- ユーザー単位で最新支援履歴を確認する
- ランキング形式で傾向を確認する
- 不要データを手動削除する
- `VCT_SB_V1` 本体設定を UI から変更する

3. ビュー構成

Supports
- 支援履歴一覧
- 検索 / 絞り込み
- 詳細カード
- 個別削除

Users
- ユーザー一覧
- 支援回数 / 通貨別累計支援額の集計
- 来訪stream数 / 最終来訪stream の簡易表示
- ユーザー情報カード
- 来訪stream履歴
- 最新支援履歴

Ranking
- ユーザー集計ベースのランキング表示
- プリセット切替
- 主要通貨指定の金額ランキング
- 配信 / 期間単位での傾向確認

Settings
- 本体設定の現在値表示
- 保存済み設定の保存 / 初期化
- 保存前プレビュー

State
- 現時点では未実装

4. Supports ビュー仕様

絞り込み条件:
- ユーザー名部分一致
- `userKey` 完全一致
- `streamId`
- `platform`
- 日付 from / to
- 金額 min / max
- 並び順

絞り込みは AND 条件。
`streamId` と日付範囲を併用した場合は、両方に一致する履歴だけを表示する。

5. Users ビュー仕様

絞り込み条件:
- ユーザー名部分一致
- `userKey` 完全一致
- `streamId`
- `platform`
- 日付 from / to
- 並び順

Users ビューでは金額条件は使わない。
支援関連の数値は `supports` から再集計して表示する。
`users.recentStreamIds` がある場合は、一覧で来訪stream数と最終来訪streamを軽く表示する。
`lastSeenStreamId` が `YYYYMMDD` 形式の場合のみ、補助情報として `今日` / `n日前` を表示してよい。

並び順:
- 新しい順 / 古い順
- ユーザー名昇順 / 降順
- 支援回数が多い順 / 少ない順
- メンギフ件数が多い順 / 少ない順

6. Ranking ビュー仕様

指定項目:
- ランキング表示プリセット
- `streamId`
- 日付 from / to

プリセット:
- 支援回数ランキング
- メンギフ件数ランキング
- 最新支援者順
- ユーザー名順
- 主要通貨金額ランキング

主要通貨金額ランキング:
- `主要通貨` の選択が必要
- 通貨候補は現在条件に一致する `supports` から抽出する
- 空値 / `UNKNOWN` / `SPONSORGIFT` は候補に含めない
- 選択通貨の累計が 0 のユーザーはランキング対象外とする

7. 詳細表示

Supports:
- 支援情報カード
- 送信者情報
- メッセージ
- 必要時のみ raw データ

Users:
- ユーザー情報カード
- 権限フラグ
- 支援回数
- 通貨別累計支援額
- 最終観測 / 最終支援
- 最終来訪stream / 来訪stream数
- 来訪stream履歴
- 最新20件の支援履歴
- 必要時のみ raw データ

8. データ管理

サイドバー下部に以下を持つ。

- `このStreamを削除`
- `supports を全削除`
- `users を全削除`

危険操作は画面内モーダルを開き、注意文の確認とロック解除後に実行する。

9. 設定管理

`VCT_SB_V1/config.js` を初期値として読み込む。
保存済み設定があれば `localStorage` を優先する。

Settings タブで扱う主な項目:
- タイトル
- `startX`
- `startY`
- `endX`
- `streamId`
- 表示件数
- 表示順
- コメント最大文字数
- レイアウト系数値
- `cardColorMode`
- `cardBackgroundOpacity`
- 表示 ON/OFF
- 空表示メッセージ
起動時初期化設定は V1 本体では扱わない。
削除操作はサイドバーの明示操作、または VCT_Core の管理UIで行う。

設定補助:
- 一部数値項目は数値入力とスライダーを併用する
- 1920x1080 想定のプレビューで、保存前に表示位置と見え方を確認できる

10. OBS 向け方針

- DevTools 前提にしない
- `alert()` に依存しない
- 詳細は画面内オーバーレイで確認する

11. 現時点の位置づけ

- `VCT_SB_V1` の管理ツール
- VCT_Core DB を利用する表示テンプレート向け管理UIの試作基盤
- `v1.0.0dev` 段階の配布候補

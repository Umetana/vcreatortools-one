# View Comment Flash V2.1

VCT SDK v2.0.3-dev 対応の、わんコメ用コメント表示テンプレートです。
`custom_base_template_V2` をベースに、ギフト・メンバーシップコメントへのビジュアル演出を追加した配信向けコメントビュアーです。

---

## 主な機能

- Vue 3 + OneSDK によるコメント購読
- VCT SDK v2.0.3-dev の `normalize()` 対応（SDK 1系へのフォールバックなし）
- 通常コメント / スパチャ / Super Sticker / メンバーシップ加入・継続・ギフト / 固定コメントの表示
- ユーザー名、アイコン、バッジ、イベントラベル（スパチャ金額など）の分離表示
- イベント種別ごとの本文表示フィルター
- YouTube自動翻訳文の表示切り替え
- `config_editor.html` による設定の GUI 編集と上書き保存
- ギフト・メンバーシップコメントへのビジュアル演出（7種類）

---

## ギフト演出一覧 (GIFT_EFFECT)

ギフトやメンバーシップ系コメントに対して、以下の演出から1つを選択できます。

| 値 | 演出名 | 概要 |
| :--- | :--- | :--- |
| none | なし | 演出なし。フラットなすりガラス枠のみ |
| glow | 発光（グロー） | ギフト色のネオン調の光が枠の周囲ににじみ出します。 |
| shimmer | シマー | 発光に加え、斜めの柔らかい光の帯が約4秒周期で走り抜けます。 |
| glint | グリント | 発光に加え、カード右上で大小の星がきらっと輝きます（約5秒周期）。 |
| sweep | スイープ | 発光に加え、白く細い光のラインが素早くカードをスキャンします。 |
| aurora | オーロラ | 発光に加え、ギフト色グラデーションが色相を変化させながら波打ちます（約8秒周期）。 |
| trace | トレース | 発光に加え、ギフト色の光の粒子がカードの境界線に沿って周回スクロールします。 |

> Note: glow 演出（外周のネオングロー）は none 以外のすべての演出に共通して適用されます。

## 設定項目一覧 (config.js)

設定は `config_editor.html` をブラウザで開いてGUIから変更・保存するか、`config.js` を直接編集してください。

### 基本表示設定

| キー | 説明 | デフォルト |
| :--- | :--- | :--- |
| MAX_ITEMS | 画面内に表示するコメントの最大数 | 8 |
| MAX_WIDTH | コメント枠の最大横幅 | "900px" |

| キー | 説明 | デフォルト |

## V2.1の変更と設定UI

現行V2を変更せずフォークした単体版です。コメント処理はbase V2.8から移植し、SDK V2のジュエル判定・表示ラベル・加入案内文に対応しました。ギフト画像の専用アニメーション追加は対象外です。

右下へマウスを重ねるとギアが表示されます。OBSでは「対話」から操作してください。設定UIは初回クリック時に読み込まれます。演出7種類、文字、色、配置などを保存前に確認でき、閉じると設定値が戻ります。表示件数を減らして除かれたコメントは復元されません。自動非表示時間は新規受信分から適用されます。

保存先はブラウザのlocalStorageで、config.js自体は変更しません。適用順は初期値→config.js→保存済み差分です。保存時は画面を再読み込みし、表示中コメントはリセットされます。ローカル設定を削除するとconfig.jsへ戻ります。フォルダ名ごとに保存領域が分かれ、V2の設定ファイルの値はコピー済みです。

パネルの左右移動・折りたたみ・同梱カラーピッカーに対応します。背景色は従来のBG_GLASS（rgba形式）を維持します。base専用の透明化プリセットや追加枠線設定は導入していません。発光演出中の枠線は従来どおり演出側の色が優先されます。

ローカルサーバー運用時はURLに ?settings=1 を付けると設定UIを自動表示できます。同じオリジン・保存領域の画面間では保存通知により再読み込みします。外部ブラウザとOBSの設定保存領域は別です。通常のローカルファイル運用にサーバーは不要です。

## 検証記録

同梱のtests/browser.cjsで、独立したChrome環境と模擬OneSDKを使用し、HTTP・file起動、通常・ジュエル・スパチャ・固定・メンバー表示、重複排除、7演出切り替え、翻訳、プレビュー取消、保存・削除、クリアを確認しました。JavaScript構文チェックも通過しています。2026-09-12に利用者から動作確認および新ギフト（ジュエル）の演出確認の報告を受けています。ランダム抽選と固定演出切り替え時の抽選結果保持もブラウザテストで確認しました。


## コメントごとのランダム演出

ギフト演出で `random` を選ぶと、ギフト・メンバー系コメントごとに `glow` / `shimmer` / `glint` / `sweep` / `aurora` / `trace` の6種類から等確率で抽選します。`none` は抽選対象外です。同じ演出が続く場合もあります。表示済みコメントの抽選結果は、設定プレビューや固定演出からの切り替えでも保持します。固定演出と「なし」も従来どおり選べます。既定値は `shimmer` のままです。

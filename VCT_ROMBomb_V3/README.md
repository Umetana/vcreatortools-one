# VCT ROM爆弾 V3 · 0.3.0

フォルダ名は `VCT_ROMBomb_V3`。V3は基盤の世代、0.3.0はこのテンプレートのバージョンです。

コメント後の無言時間に応じて爆弾が育ち、再コメントで解除される配信演出です。配信者を除外し、モデレーターは初期設定で除外します。コメントのない人の視聴状況や在席を判定するものではありません。

ミニカード表示、爆弾・爆発の脈動、カード爆散、Emoji/Visual切替、経過／残り時間、縦横・折り返し・ランダム配置、全体のマウス移動・拡縮に対応しています。

## 動作環境

OBS Studio 33.0.1（64bit）・わんコメ9.2.0-beta.13で基本動作を確認しています。機能ごとの検証範囲と自動試験の条件は[検証](TEST_RESULTS.md)を参照してください。

## 使用方法

1. `VCT_ROMBomb_V3` をわんコメのカスタムテンプレートへ配置します。
2. OBSブラウザソースのローカルファイルに `index.html` を指定し、幅1920・高さ1080にします。
3. OBSの「対話」で右下へマウスを置くと歯車が表示されます。クリックして設定を開きます。通常ブラウザでは `index.html?settings=1` で設定を開けます。
4. 「変更を保存」で再読み込みせず反映します。閉じると未保存の設定は取り消します。「保存して再読み込み」は監視データも初期化します。
5. 効果音を使う場合は、OBSのブラウザソースのプロパティで「OBSで音声を制御する」にチェックを入れます。OBSの音声ミキサーで該当ソースのミュート・音量を確認してください。

旧フォルダ名 `view_comment_ROMBomb` から変更する場合は、OBSブラウザソースのファイル参照も新しい `index.html` へ変更してください。フォルダ名の変更で設定の保存先が変わり、旧設定は自動移行しません。設定は新しいフォルダで行ってください。

初期値は表示までの無言時間5分、登場後の警戒10分・危険15分・爆発20分、最大10人です。最後のコメントから5分待って登場し、その瞬間を経過00:00／残り20:00として数え始めます。上限枠に空きがあれば、コメントから合計25分後に爆発します。表示待ちと登場後の時間は別設定です。時間は小数の分も指定でき、登場後は「警戒 < 危険 < 爆発」が必要ですが、表示待ち時間と警戒時間の前後関係は問いません。最大表示人数は1～30人です。

以前の累積時間方式から、設定値の数値は変更せず意味を更新しています。既存設定でも警戒・危険・爆発は登場後の時間になります。更新時は再読み込みして新しい仕様で開始してください。

## 爆弾表示後の解除条件

初期値は「すべてのコメント」です。設定の「爆弾表示後の解除条件」で次の方式を選べます。変更は保存後の新しいコメントから適用し、受信済みコメントは再判定しません。

| 方式 | 解除できるコメント |
| --- | --- |
| すべてのコメント | 従来どおり、どのコメントでも解除 |
| 指定ワード以外 | 指定ワードに完全一致しないコメント |
| 指定ワードのみ | 指定ワードのいずれかに完全一致するコメント |

「解除に使えないワード」（指定ワード以外用）と「解除に必要なワード」（指定ワードのみ用）は別々の入力欄で保存します。モードを変えても両欄の内容を保持するため、ワードの再入力は不要です。各欄は初期値が空欄で、1行に1件、各2048文字以内です。空行は無視し、コメント本文と各ワードの前後の空白を除いて比較します。本文はVCT SDKで取得したプレーンテキストを使います。部分一致・正規表現は使わず、大文字小文字・全角半角・句読点は区別します。「指定ワード以外」「指定ワードのみ」は、選択した側の欄に有効な行がない場合のみ保存エラーになります。選択していない側の空欄は問題ありません。以前の共通ワード欄に保存された設定は、ワードを両欄へ引き継ぎます。

爆弾がまだ一度も登場していない人は、表示枠を待っている間も含め、どのコメントでも待ち時間をリセットします。登場後は、条件に合わないコメントで解除・タイマーリセット・新しい監視サイクルへの切替を行いません。一度登場した爆弾は、その後に枠外へ移動した場合やカウント一時停止中も同じ解除条件を使います。爆発後の新規登録は通常どおり受け付けます。

ワードの内容と視聴者への周知は配信者が行ってください。テンプレートはワード候補・お題・自動告知・画面内への解除ワード表示を提供しません。

## 表示と一時停止

### 全体をマウスで配置する

設定の「マウス配置を開始」で、グループ全体の編集枠を表示します。枠をドラッグして移動、枠内のホイールで倍率を変更できます。位置・倍率のスライダー／数値入力も連動し、粗い配置の後に微調整できます。パネルが邪魔な場合は上部の「—」で折りたたんで操作します。カードが出ていない間も1枚分の編集枠で配置できます。

「変更を保存」で確定し、閉じると未保存の配置を取り消します。「マウス配置を終了」、保存、パネルを閉じる、ページが非表示になるとマウス編集を終了します。倍率はホイール0.05刻み・数値入力0.01刻み、位置は数値入力1px刻みです。表示位置に応じた四隅を基準に移動・拡縮します。個別カードの配置ではありません。

「表示位置（四隅プリセット）」を選ぶと、1920×1080の選択した四隅へ、左右20px・上下100pxの初期余白で配置し直します。移動後の余白を引き継がず、倍率・並べ方・間隔は保持します。同じ四隅へ戻す場合は「この四隅に戻す」を押してください。その後にマウスや数値で微調整し、保存できます。再読み込み・設定パネルを開く操作だけでは、保存した位置を初期化しません。

### ランダムに点在させる

「並べ方」で「ランダム配置」を選び、範囲の左位置・上位置・幅・高さを指定します。初期範囲は画面全体1920×1080で、画面内の小さい範囲にも設定できます。「マウス配置を開始」で範囲をドラッグ移動でき、ホイールは各カードの倍率をまとめて変更します。幅・高さはスライダー／数値で指定します。範囲が画面外へ出る設定は適用しません。

各カードの中心位置を範囲内から独立に抽選します。重なり回避・見切れ回避・空き場所への詰め直しは行いません。カードや成長した爆弾は指定範囲からはみ出してよく、画面外の部分だけが見切れます。位置は同じ監視サイクル中は固定し、表示上限によって一時的に枠外へ出ても保持します。解除後に再登場するときは新しい位置を抽選します。

ランダム配置中も最大表示人数と対象者の選定は従来どおりです。範囲を変更すると、各カードの範囲内での相対位置を保って移動します。縦横・折り返し用の四隅・オフセット・間隔の設定は保持し、縦並び／横並びへ戻すと再び使用します。座標は保存せず、設定だけを保存します。

### 共通の表示とカウント

「ビジュアルモード」でEmoji mode（初期値）／Visual modeを切り替えられます。Emoji modeは従来の💣・💥、Visual modeは同梱の生成画像による爆弾・爆発とカードの縁取りを使います。成長・脈動・タイマー・配置は共通です。解除はどちらも✨です。画像の読み込み中・失敗時は絵文字を表示します。モードは保存前にプレビューでき、閉じると取り消します。

素材は `assets/visual/bomb.png` と `explosion.png`。テンプレートをコピー・配布する際もassetsを含めてください。制作方法と生成プロンプトは `assets/visual/README.md` に記録しています。

表示用素材は512×512へ軽量化済みです。原寸は `asset_original/visual` に保管し、実行時には読み込みません。通常配布ではasset_originalと制作専用のtoolsを省略できます。

「爆発時にカードを爆散させる」（初期値OFF）をONにすると、爆発時にカードが6片へ分かれて飛び散ります。💥は従来の演出時間で表示し、破片は最大1.2秒で消えます。名前は短くフェードします。爆発演出そのものがOFFの場合、爆散も行いません。画像のcanvas転写や追加ライブラリは使いません。

少し横長のミニカードにアイコンと💣を配置し、アイコンの下部に登場後のタイマーを重ねます。名前はカードの外側、下に表示し、長い名前は省略します。爆弾は段階ごとに大きくなりながら脈動し、アイコンに重なる演出です。時間は爆弾より手前に表示します。右上・左上・右下・左下、端からの距離、全体倍率、名前・時間・解除・爆発演出を変更できます。

「並べ方」で縦並び／横並びを切り替え、「カード間隔」で0～200pxの余白を指定できます。初期値は縦並び・6pxで、従来の縦方向の間隔を維持します。間隔は名前を含む固定領域（132×82px）の間の余白です。倍率を変えると間隔も一緒に拡縮します。爆弾が大きくなっても並び位置は動きません。

「折り返し人数」は0～30人の整数で指定します。0（初期値）は折り返しなしです。縦並びで3人なら上から3人並べて次の列へ、横並びで3人なら左から3人並べて次の行へ進みます。必要な列・段の数は実際の表示人数から自動計算し、指定人数に満たない場合は余分な空き枠を作りません。最大表示人数とは別の設定です。

無言時間の長い順に、縦は列ごとに上から下、その後は右の列へ、横は行ごとに左から右、その後は下の行へ並べます。表示位置はカード全体を指定した端に寄せます。横並びの右上なら、列が増えるとグループが左に広がり、右端の位置は維持します。端の指定はカード全体の位置を決めるもので、並ぶ順番は変えません。並べ方・折り返し人数・間隔も保存前にプレビューでき、閉じると取り消せます。人数・間隔・倍率を大きくすると画面外で見切れるため、配信画面に合わせて調整してください。

「時間の表示方式」で「爆弾登場からの経過時間」（初期値）と「爆発までの残り時間」を切り替えられます。残り時間は爆発までの秒数を切り上げ、爆発中は00:00を表示します。表示方式を変えても監視タイマーと対象者の順序は変わりません。登場後の爆発時間を保存し直すと、残り時間も新しい条件で計算します。表示待ち時間の変更は未登場の人へ適用し、登場済みのタイマーは巻き戻しません。

「爆発から退場まで（秒）」は0.3～30秒、初期値2秒です。💥は最初に拡大し、その後は0.8秒周期で拡大縮小して脈動しながら、最後の0.3秒でカード・名前と一緒にフェードアウトします。最短0.3秒の設定では最初の拡大とフェードだけになります。設定変更は次に始まる爆発から適用し、演出中の長さは変えません。再コメントがあれば古い爆発演出を消して新しい監視を優先します。

カウントOFF中は表示待ち・登場後のどちらにも時間を加算しません。解除条件を満たしたコメントを受け取ったユーザーは爆弾を解除し、表示待ちからやり直します。未登場の人はどのコメントでも待ち時間をリセットします。ONに戻すと保持した時間から再開します。OSのスリープは手動OFFとは異なり、ONのままなら復帰後に実際の経過時間を反映します。

表示・配置は設定編集中にプレビューできます。履歴を消すような操作を取消時に戻せなくなることを避けるため、監視ON/OFF・時間条件・人数・対象者・演出条件は保存時に適用します。設定だけを既存VCT方式でlocalStorageへ保存し、リスナー情報は保存しません。ブラウザとOBSは設定の保存先が異なる場合があります。

## 効果音

「爆発時に効果音を鳴らす」をONにして保存すると、爆発の開始時に鳴らします。「効果音の種類」で短い「ボフッ」系の「JS合成」（初期値）と、同梱素材を使う「MP3（SUNO生成音）」を選べます。初期値はOFF、音量は30%で、0～100%に調整できます。種類・音量とも保存時に適用します。実行時の外部サービス接続や追加ライブラリは不要です。爆発演出OFF時と解除時は鳴りません。

「効果音を重ねる」は初期値OFFです。OFFでは400ms以内の連続・同時爆発を一発にまとめ、MP3再生中の追加爆発も重ねません。ONでは別のカードの爆発音を最大3音まで同時再生し、上限を超えた分は鳴らさず、後から再生もしません。JS合成・MP3の両方に適用します。同じカードの脈動中に繰り返し鳴ることはありません。MP3は末尾をカットした約4秒版です。通常のカード退場では音を途中で切らず、効果音OFFの保存・種類や重ね方の変更・確認表示の終了・ページ終了時に停止します。素材は `assets/sound/Explosion Sound.mp3` です。読込・再生に失敗した場合は設定パネルに案内を表示し、別の音へ自動切り替えしません。

「爆発音を試聴」はON/OFFにかかわらず、編集中の種類・音量で一音ずつ再生します（0%は無音）。自動再生が制限される環境では、OBSの「対話」から試聴を操作してください。再読み込み後に再操作が必要になる場合があります。開始できなかった音は後からまとめて再生しません。配信へ音を出すにはOBS側のブラウザソースの音声設定・ミキサーも確認してください。「短時間で演出を確認」でも保存済みの効果音設定を使います。

## 短時間の表示確認

設定パネルの「短時間で演出を確認」で確認表示を開始します。初期値では約9秒で、設定した爆発演出時間に応じた所要時間を画面内ラベルに表示します。テスト専用の別データで登場・段階変化・一人の解除・爆発を確認でき、本番の登録者と設定を書き換えません。「確認表示を終了」、設定パネルを閉じる、または自動終了で本番表示に戻ります。確認中も実コメントを受け取り、すでに登場した人の時間は進みますが、未登場の本番ユーザーは確認表示の裏で登場扱いにせず、本番表示へ戻した時点からタイマーを開始します。画像の読込失敗時は👤を表示します。

## 受信条件と制限

- VCT SDK 2.0.3-devと既存の公開OneSDK連携を使用します。OneSDKは隣接する `../__origin/js/onesdk.js` を参照し、わんコメ本体・SDKを新たに同梱しません。
- 起動前のタイムスタンプを持つコメント、システム通知、メンバー加入・ギフト通知等は登録しません。通常コメント・本文付きスーパーチャット・メンバー継続コメントを対象とします。
- サービスID・ユーザーID・コメントID・有効なコメント時刻が欠けるデータは登録しません。同名ユーザーの取り違えを防ぐため、名前による代替識別はしません。
- 重複はサービスIDとコメントIDで抑止します。重複履歴は期限付きで掃除し、古い再送も時刻で除外します。受信時刻を無言時間の起点とします。
- コメント時刻とPC時刻を比較します。PC時刻のずれ、起動前の投稿が遅れて届く場合は対象から外れることがあります。PCより1分を超えて未来のコメントも除外します。
- 無言時間の長い順に上限人数を表示します。枠待ち後の初登場も経過0から開始します。一度登場した人は枠外でもタイマーが進みます。一度も登場しない人は「表示待ち＋登場後の爆発時間」で期限切れ処理し、無制限に保持しません。爆発演出は表示されていた人だけです。解除・爆発中も表示上限に含めます。
- わんコメのコメントクリアで監視データを消去します。設定は保持します。
- 履歴保存・DB・外部サーバー・個別ユーザー除外・個別カードのドラッグはありません。アイコン画像の表示には取得元へのアクセスが発生する場合があります。

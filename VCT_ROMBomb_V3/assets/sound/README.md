# 爆発効果音

`Explosion Sound.mp3` はUmetanaがSUNOの有料プラン契約中に生成した、本テンプレート用の爆発効果音です。実行時にはSUNOへ接続しません。

- 形式：MP3、48,000Hz、ステレオ
- 長さ：約5.57秒
- 容量：152,197 bytes
- SHA-256：`84a2a2811339a113bf3d16facb52d4707200aa38094dcb5ef1b9706601134df3`

素材は受領したファイルを無加工で使用しています。生成元の条件は[SUNO利用規約](https://about.suno.com/terms)と[有料プランの権利に関する公式説明](https://help.suno.com/en/articles/9601665)を参照してください。ソースコードと生成素材の権利・条件は区別して扱います。

設定の「効果音の種類」でMP3を選びます。試聴は編集中の種類・音量で再生し、爆発時は保存済み設定を使います。

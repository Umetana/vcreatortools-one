# 爆発効果音

`Explosion Sound.mp3` はUmetanaがSUNOの有料プラン契約中に生成した、本テンプレート用の爆発効果音です。実行時にはSUNOへ接続しません。

- 形式：MP3、48,000Hz、ステレオ
- 長さ：約4.00秒
- 容量：92,268 bytes
- SHA-256：`c671bb8659ad3814dbe286f99f58d286ec57ae17936b3269fffbd8d69c2ed39d`

生成音の末尾をカットした約4秒版を使用しています。生成元の条件は[SUNO利用規約](https://about.suno.com/terms)と[有料プランの権利に関する公式説明](https://help.suno.com/en/articles/9601665)を参照してください。ソースコードと生成素材の権利・条件は区別して扱います。

設定の「効果音の種類」でMP3を選びます。試聴は編集中の種類・音量で再生し、爆発時は保存済み設定を使います。

# VCT ROM爆弾 V3 · 0.1.0 検証

## 動作確認環境

| ソフトウェア | バージョン |
| --- | --- |
| OBS Studio | 33.0.1（64bit） |
| わんコメ | 9.2.0-beta.13 |

基本表示、登場後を起点にした時間表示、縦横・折り返し配置、マウスによる全体移動・拡縮、ランダム配置、四隅プリセットの動作を確認しています。カード爆散・Visual mode・512px素材の組み合わせはChromeで検証しています。配信サイト別の網羅試験と、実時間による長時間連続稼働試験は実施していません。

## 自動検証

検証環境：Windows、Node.js 24.22.1、Chrome 156.0.8078.80。実コメントの代わりに模擬データを使用し、実OneSDKへの接続と検証用localhost以外への通信を遮断します。

| コマンド | 結果 | 対象 |
| --- | --- | --- |
| `node --test tests/engine.test.cjs` | 13件成功 | 時間境界、停止再開、解除・再登録、重複・履歴除外、対象者除外、表示上限、枠外の期限処理、設定検証 |
| `node --test tests/audio.test.cjs` | 7件成功 | 音量0、同時爆発の抑止・最大3音の重ね再生・終了後の枠再利用、MP3音量・終了・停止・再生拒否・読込失敗・開始待ち取消、発音解放、非対応環境 |
| `node tests/browser.cjs` | 成功 | HTTP/file起動、透過表示、設定保存・取消、配置・拡縮、画像読込、爆発・爆散 |

主な確認内容：

- 5分待って登場した時点で経過00:00／残り20:00となり、登場後10分・15分・20分で段階が進むこと。枠待ち後の初登場も0秒から始まること。
- 表示待ちと登場後の両方で一時停止が機能し、停止中のコメントで表示待ちからやり直すこと。
- 初期履歴・重複・識別情報の欠落・システム通知を除外し、サービス間でユーザーIDを分離すること。
- 1,000人を登録した模擬試験で、時刻を2時間進めた後に監視・演出・重複履歴が期限処理されること。
- 四隅・倍率・縦横・折り返し・カード間隔の配置、縮小プレビューのマウス座標補正、数値とスライダーの連動。
- ランダム配置で範囲内に中心を置き、重なりや範囲からのはみ出しを許容すること。表示上限の変更で再抽選せず、新しい監視サイクルで位置を更新すること。
- 生成画像の読込、Emoji/Visualの切替と取消、画像失敗時の絵文字代替、保存再読込。
- 爆散の6分割、二重生成の抑止、破片の後片付け、再コメント時の削除、爆発演出OFF時の抑止。
- 実AudioContextによる試聴、初期OFF時にContextを作らないこと、重ね方の初期値OFFで同時爆発の発音が一度であること、プレビューによる再発音の抑止、OFF保存後の無音、音量の保存・再読込。JS合成の基本動作はOBSでも確認済み。4秒版MP3はHTTP/file両方で実ファイルの試聴・同時爆発・最大3音の重ね再生・音量・全音停止・種類の取消と重ね方の保存再読込を検証。検証用Chromeの音声出力はミュートし、MP3のOBS音声出力と聴取確認は未実施。
- 名前をテキストとして描画し、HTML風の名前からHTML要素を生成しないこと。
- 正式フォルダ名でHTTP/file起動でき、設定キーが `vct.template-settings.vct_rombomb_v3.v1` となること。改名前の保存設定を自動移行せず、初期設定で起動すること。

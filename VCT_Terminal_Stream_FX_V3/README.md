# VCT Terminal Stream FX V3

試作版 0.5.5。バージョンはわんコメのテンプレート名と対話の設定パネルに表示します。V3は基盤の世代です。

配信者の背後に重ねる透過背景演出の試作です。手前に実コメントと疑似ログ、奥に小さく薄い疑似ログが流れます。実コメントは手前の疑似ログ一行分の枠を使い、登場時だけ少し明るく表示されます。疑似ログに表示する通信状態や識別子は演出用です。

## OBSで試す

1. ZIPの場合は展開した `VCT_Terminal_Stream_FX_V3` フォルダをわんコメのカスタムテンプレートフォルダに置きます。わんコメを起動し、`VCT Terminal Stream FX V3 v0.5.5（試作）` をOBSへ追加します。ローカルファイルを選ぶ場合は `index.html` を指定します。
2. ブラウザソースの幅を1920、高さを1080に設定し、背景映像より手前、アバターより奥へ配置します。
3. コメントが来ない間の見え方、コメントが入った瞬間の明るさ、会話中の視線の移り方を、普段の配信シーンで確認します。

実コメントは `[RX] 表示名 > 本文` の形式で流れます。本文中の文字・絵文字・画像は元の順序で一行に並べ、幅を超える部分は末尾で省略します。画像だけの投稿も一行として流れます。画像が表示できない場合は代替テキストを使い、代替テキストが空なら「[絵文字]」または「[スタンプ]」を表示します。

短時間に集中した場合は未表示の新しい8件を優先し、6秒を超えて待ったコメントは破棄します。表示待ちのデータはページ内のメモリで扱います。わんコメから消去を受信すると待機中・表示中の実コメントを消去します。

## 支援・メンバーシップとコメント書式

- `flow`（初期値）では、サブスクを `[SUB] 表示名 > 加入通知`、スパチャを `[SC ¥1,000] 表示名 > 本文` のように一行で表示します。メンバーシップギフトの件数が取得できたときは `[GIFT ×5]` のように表示します。ギフト色が取得できたときは行頭のラベルに使います。
- `json` では、実コメントをキーと値で色分けした一行のJSON風表示にします。金額と件数は取得できたときに `amount` と `count` に表示します。本文の画像も `msg` 内で元の順序を保ちます。

どちらの書式でも、疑似ログはシステムログ・JSON風データ・16進データが混ざった形式で流れます。

設定パネルの「コメント書式」で標準とJSON風を切り替えられます。表示中の実コメントにも反映されます。保存値がない場合は `config.js` の書式を使用します。URLで `?mode=json` または `?mode=flow` を指定した場合は、その書式が優先されます。

VCT SDKとUI部品は `lib` に同梱されています。実コメントの受信にはわんコメの起動と、従来どおりカスタムテンプレート環境の `../__origin/js/onesdk.js` が必要です。

## OBSの対話で配置する

パネル上部の「設定UIの大きさ」で標準・中・大を選べます。変更はすぐ反映され、「保存」で次回も使うサイズとして記録します。

表示・コメント書式・演出・流れ方・流す内容は、現在値のボタンを押し、設定パネルの上端と右端に重なる選択ダイアログで候補を選んで「決定」を押します。「決定」でプレビューに反映され、設定パネルの「保存」で記録されます。

OBSのブラウザソースで「対話」を開き、右下にマウスを乗せて歯車をクリックします。「ウインドウ」に切り替えると、点線の枠をドラッグして移動できます。X・Y・幅・高さ・傾き（±30°）は数値でも調整できます。ログは透過ウインドウの内側を流れ、長い行や画面外にはみ出した部分は見切れます。

「保存」で現在のブラウザ環境に配置を保存し、「取消」または Esc で保存済みの配置に戻ります。全画面で保存した場合もウインドウの位置・寸法・傾きを保持します。URLで追加する場合は `?ui=0` で歯車を無効にできます。

全画面の傾きはウインドウと別に保存します。傾けたときは、回転した描画領域が画面の四隅まで届くように広がります。ウインドウでは「枠・ヘッダー」をオンにすると、細い枠と Terminal のタイトルバーが付きます。

ウインドウの上限は幅3840・高さ2160です。傾けたウインドウを画面外まで広げられます。OBSに映る範囲はブラウザソース内です。「数値を初期化」で X=100、Y=140、幅1000、高さ700、傾き0°に戻します。初期化はプレビューに反映され、「保存」で確定します。

## 演出・流れ方・内容

- 「演出」は、二層表示の Cyber Data Flow と、時刻付きで一層表示の Terminal Log から選べます。
- 「流れ方」は、連続スクロール、上端に新着が入る「上積み」、下端に新着が入る「下積み」から選べます。
- 「流す内容」は、実コメントと疑似ログの混合、実コメントのみ、疑似ログのみから選べます。実コメントのみの積み上げでは、新着が来るまで表示済みの行が残ります。

枠付き端末として使う場合は、ウインドウ表示で「枠・ヘッダー」をオンにして、Terminal Log と下積みを選びます。演出・流れ方・流す内容を変えると表示中のログが入れ替わります。「取消」で設定値を戻せます。

「奥行き」は −35°〜35° です。正の値で上側が奥に見え、負の値で下側が奥に見えます。傾きと組み合わせると斜め奥へ抜ける見せ方ができます。全画面とウインドウの値は個別に保存し、初期値はそれぞれ 0° です。全画面は角度に合わせて描画領域が広がり、ウインドウは枠とヘッダーごと傾きます。「数値を初期化」ではウインドウの奥行きも 0° に戻ります。

## 色・不透明度

設定パネルの「色・不透明度」を開き、色欄をクリックするとインラインカラーピッカーが開きます。HEX値を色欄に入力することもできます。奥の文字色は奥の層を表示するときに調整できます。

不透明度は、テキスト・絵文字・スタンプを含むログ全体に適用します。100%は従来の濃さ、0%はログを非表示にします。ギフトラベルには取得したギフト色を使い、ウインドウの枠とヘッダーはログの不透明度から独立しています。設定は即時にプレビューされ、「保存」で確定します。「色・不透明度を初期化」で既定値をプレビューできます。

# VCT StreamOS v0.2.0-alpha.2 試作

コメントログとギフト風通知を表示する架空のデスクトップです。配信者が話しながら操作できるか、視聴者に演出が伝わるかを確認するための試作です。

## 導入

ZIPを展開し、`VCT_StreamOS` フォルダーをわんコメのカスタムテンプレートに追加してください。フォルダー内の `index.html` をOBSで開けます。共通UIとVCT SDKは同梱されています。コメント・配信情報を受信するにはわんコメの起動が必要です。模擬入力はわんコメ未接続でも使えます。

クレジット表記の要否は、[わんコメ利用規約](https://onecomme.com/terms/)の「クレジット表記について」を確認し、規約に従ってご利用ください。

## OBSで試す

1. ブラウザソースの「ローカルファイル」を有効にし、このフォルダの `index.html` を選びます。幅1920、高さ1080に設定します。
2. ソースを右クリックして「対話」を開きます。コメントログをタイトルバーでドラッグし、OBSのプレビューにも移動が反映されることを確認します。右上の「×」で閉じ、左下の「StreamOS」から「コメントログ」を選ぶと開けます。「−」で最小化するとタスクバーに残り、タスクバーのボタンを押すと復元できます。タスクバーのボタンは、背面のログを前面に出し、前面のログをもう一度押すと最小化します。
3. 「StreamOS」から「設定」を開きます。タスクバー右端の歯車からも開けます。「模擬コメント」や「模擬ギフト」を押して表示を確認します。表示中の通知は「システム通知」の見出しをドラッグして移動できます。「位置を戻す」で各ウィンドウと通知が初期位置に戻ります。タイトルバーの「×」か Esc で設定を閉じます。
4. OBSのブラウザソースを再読み込みして、ログの位置と開閉・最小化状態が戻ることを確認します。

設定パネルは起動時に閉じています。設定パネルもデスクトップの一部として配信画面に表示します。スタートメニューは項目を選ぶか、メニューの外をクリックするか、Escを押すと閉じます。

「StreamOS」の「ギフトログ」で、ギフト専用ウィンドウを開けます。通常のコメントログにも同じギフトが残ります。ギフトログでは、イベントごとの色設定がオンで色を取得できた行に色が付きます。通常のコメントログは、コントロールパネルの「ログ・通知」にある「コメントログにイベント色を表示」でギフト行の背景色を切り替えられます。初期値はオフです。

設定の「共通」で「配信画面にカーソルを表示」をオンにすると、OBSの「対話」でマウスを動かした位置に疑似カーソルが出ます。設定の初期値はオフです。操作画面の外へ出るか、約2.5秒間マウスを止めると消えます。

## コントロールパネル

背景やテーマなどの選択ボタンを押すと、共通の選択ダイアログがStreamOSの画面中央に開きます。候補を選んで「決定」を押すと反映し、「キャンセル」や Esc で閉じると元の選択が残ります。

スタートメニューの「設定」または歯車から開き、タイトルバーで移動できます。「共通」に背景、配信情報の数値サイズ、位置リセット、模擬入力があります。「ログ・通知」ではコメントログとギフトログそれぞれの文字サイズ（16〜48 px）、保持件数（1〜100件）、バッジ表示を設定できます。初期値は26 px、8件、バッジ非表示です。文字サイズとバッジは表示済みの行にも反映し、保持件数を減らすと古い行から削除します。件数を増やした分は、その後の受信から蓄積されます。

イベントごとのコメントログ、ギフトログ、通知、ログの色も設定できます。

初期値ではメンバー加入・継続・メンギフ受取をコメントログに表示します。ギフトログは支援イベント、通知は支援イベントとメンバー加入が対象です。表示先の変更は次に受信するイベントから反映し、色の変更は表示済みの行にも反映します。

「ウィンドウ」では各ログ、画像フォルダー、画像ビューアの表示倍率を 50〜150% で設定できます。初期値は 100% です。入力を確定すると文字やボタンを含めたウィンドウ全体に反映し、再読み込み後も復元します。OBSの「対話」でタイトルバー上にポインターを置き、Ctrl＋ホイールを使うと5ポイントずつ調整できます。変更は「ウィンドウ」の数値にも反映されます。

各ログ、画像フォルダー、画像ビューア、配信情報は、ウィンドウの端や四隅をドラッグして幅・高さを調整できます。ウィンドウにポインターを置くと四隅に目印が出て、つかめる辺や角に重ねると青くなります。「共通」の「サイズ変更の目印を表示」で両方の目印を切り替えられます。初期値はオンです。目印をオフにしても端や四隅をドラッグできます。文字サイズと倍率を保ったまま表示領域が変わります。枠の高さと文章の折り返しによって、保持したログのうち画面に見える行数が変わります。サイズは保存され、再読み込み後も復元します。

## 時計・タイマー

「設定」の「共通」で、タスクバーの時計に12時間表記、日付、曜日、秒を個別に指定できます。初期値は時・分だけの24時間表記です。

スタートメニューの「時計・タイマー」は、好きな位置に移動して現在時刻か配信経過時間を表示できます。経過時間は手動で開始・一時停止・再開でき、「リセット」で停止してゼロに戻ります。計測中にウィンドウを閉じたり、ソースを再読み込みしたりしても、開始時刻から計測を続けます。

## 配信情報

わんコメのOneSDKから同接と高評価を取得し、タスクバーの時計横に表示します。「共通」の「タスクバーに配信情報を表示」で切り替えられます。スタートメニューの「配信情報」を開くと、同じ数値を移動・最小化できるウィンドウでも表示できます。数値の文字サイズは「共通」で28〜56 pxから選べます。初期値は44 pxです。片方だけ取得できた場合は、その項目に横幅を使います。

複数枠がある場合は、最初に有効な数値を取得できた1枠を表示します。枠の配信情報がクリアされると次の更新を待ちます。取得できない項目は省略し、両方とも未取得の場合はウィンドウに待機表示が出ます。

## デスクトップテーマ

「外観」の「デスクトップテーマ」で標準・クール・キュート・カスタムを選べます。カスタムでは現在のテーマを土台に、タイトルバー、タスクバー、地色、本文、枠線の色と、書体・角の形を調整できます。色欄を押すと共通のインラインカラーピッカーが設定の横に開き、調整中の色欄に枠が付きます。右側に収まらない場合は左側に表示されます。変更は即時に反映され、カスタム設定はほかのテーマに切り替えても保存されます。「土台の外観に戻す」でカスタムの変更をリセットできます。ウィンドウ、タスクバー、スタートメニュー、コントロールパネルの配色・書体・角丸・枠線が切り替わります。書体は利用できるフォントを使います。テーマと数値サイズは保存され、背景は独立して選べます。

カスタム外観は3枠に保存できます。「外観」でプリセットの枠を選び、「保存」または「上書き保存」を押します。「呼び出す」で保存した土台、色、書体、角の形を適用します。背景は個別の設定です。プリセットはブラウザソースを再読み込みした後も使えます。

## デスクトップ背景

「設定」の「デスクトップ背景」で、青緑（初期値）、夕暮れ、スレート、透明、画像を選べます。配色はその場で反映され、ソースを再読み込みしても選択が戻ります。透明にすると壁紙から下のOBSソースが見え、タスクバーやウィンドウは表示されます。

「画像」を選ぶと、画像フォルダーの登録画像を壁紙に指定できます。「壁紙の表示方法」で「画面を覆う」（初期値）と「全体を表示」を選べます。どちらも縦横比を保ちます。「画面を覆う」では画像の一部が切れる場合があり、「全体を表示」では余白に青緑の背景が見えます。指定した画像と表示方法は再読み込み後も復元します。画像を選んでいない間や、削除などで読み込めない場合は青緑の背景になります。

## 画像フォルダー

「StreamOS」から「画像フォルダー」を開き、サムネイルをクリックすると画像ビューアで表示できます。ビューアの「前へ」「次へ」で登録順に切り替えます。タイトルバーの「□」でタスクバーの上まで最大化し、もう一度押すと元の位置・サイズ・倍率に戻ります。

画像が2枚以上あると「スライドショー開始」を使えます。表示中の画像から登録順に切り替え、最後まで進むと先頭に戻ります。間隔は1〜120秒で、初期値は5秒です。間隔は再読み込み後も保持され、再生は停止ボタン・最小化・閉じる操作で止まります。両ウィンドウはタイトルバーで移動でき、ログと同様に最小化・復元できます。

自分の画像は `gallery` フォルダーに `01.jpg`〜`10.jpg` または `01.png`〜`10.png` の名前で置き、OBSのブラウザソースを再読み込みしてください。読み込めた画像だけを番号順に表示します。番号は飛ばしても使えます。同じ番号で両方ある場合は、読み込めるJPGを優先します。

任意のファイル名や表示名を使う場合は、これまでどおり `gallery-images.js` に `{ file: '画像.png', title: '表示名' }` を追記できます。手動登録の画像は番号付き画像の後に登録順で並び、番号付きと同じファイルを登録した場合は表示名だけが適用されます。サンプル画像2枚も手動登録されています。

重なったウィンドウを前面に出しても、ほかのウィンドウ同士の順序は保たれます。前面のウィンドウを閉じるか最小化すると、その直後ろのウィンドウが前面になります。重なり順はページを開いている間だけ保持します。

## 開発版の動作仕様

- OBSの「対話」でブラウザソースのページを直接操作します。状態の保持と描画は同じページで行います。ローカルファイルにはクエリを付けず、カスタムブラウザドックは使いません。
- ウィンドウの位置・開閉・最小化状態とログのギフト色設定はブラウザソースのローカルストレージに保存します。コメントと通知はページを開いている間だけ保持します。OBSのソース設定でシーン切替時にページを再読み込み・終了する場合、コメント履歴も消えます。
- わんコメを起動した状態でソースを開き、テストコメントを送ると受信を確認できます。接続状態は歯車から確認できます。各ログは設定した件数の範囲で最新の受信を保持し、閉じている間も受信します。本文中の絵文字とスタンプも表示します。画像を読み込めない場合は代替テキストを表示します。ギフトログの対象はイベント別に設定できます。模擬入力は接続状態にかかわらず使えます。
- OneSDKは、わんコメが用意する `../__origin/js/onesdk.js` を参照します。VCT SDKと共通UI部品には同梱のMITライセンス（`lib/LICENSE` および `LICENSE`）が適用されます。
- スパチャ、ステッカー、ジュエル、メンバーシップギフトなど、VCT SDKが支援と判定したイベントやメンバー加入は、コメントログにラベルと本文を残し、初期位置では右下にも通知します。移動した通知の位置は再読み込み後も復元します。ドラッグ中は表示を継続し、操作を終えてから約4秒で次の通知に移ります。支援イベントの色は通知ウィンドウ全体の背景に反映し、背景に合わせて文字色を黒または白に切り替えます。色が未取得の場合は標準配色を使用します。本文のないギフトもラベルで記録します。通知は約4秒ずつ順番に表示し、表示待ちは最大8件です。上限に達した場合は後から届いた通知を省きます。
- 画面内での画像登録は今後の検証対象です。

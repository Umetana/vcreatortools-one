# View Comment Halloween V2 v0.1.0-beta.1

現在は実機確認を進めるベータ版です。基本機能は実装済みですが、正式公開前にOBS環境での継続確認を行います。

10月の配信画面向けに、コメント欄と1920x1080ステージをハロウィン仕様へまとめた、わんコメ用カスタムテンプレートです。`custom_base_template_V2_8_dev` を基盤にしています。

## 現在の実装

- 1920x1080基準ステージのアスペクト比維持表示
- コメント領域の位置、幅、高さ、倍率設定
- XY・幅・高さのスライダーと数値入力、五方向の配置プリセット
- CSSと絵文字で構成する `emoji` モード
- 生成画像背景を使う `visual` モード
- ギフト配色の `original` / `hybrid` / `halloween` 切り替え
- ステージ背景を消して映像へ重ねる透明オーバーレイ表示
- コメント領域の外枠表示切り替え
- コメント背景色のインラインピッカーと透明度の個別調整
- プロフィール画像／ランダムなハロウィン絵文字／非表示のアイコン切り替え
- 設定パネルの左右切り替えとプレビュー確認用折りたたみ
- 霧、コウモリ、幽霊の常時演出ON/OFF
- 常時アニメーションを止める軽量設定
- V2.8由来のコメント表示、イベント分類、設定パネル

## 推奨OBS設定

ブラウザソースの幅を `1920`、高さを `1080` にします。異なるサイズでもステージは自動で拡大縮小されます。

画面右下のホットスポットから設定パネルを開けます。ローカルサーバー運用では `?settings=1` を付けたURLを設定用ドックに利用できます。

設定パネル上部の `⇆` で左右を切り替えられます。`—` で小さな操作バーへ折りたたむと、コメント領域がパネルの裏へ入った場合もステージ全体を確認できます。

## 主な設定

- `VISUAL_MODE`: `emoji` / `visual`
- `STAGE_FIT`: `contain` / `cover`
- `COMMENT_X`, `COMMENT_Y`: 1920x1080基準座標
- `COMMENT_WIDTH`, `COMMENT_HEIGHT`: コメント領域サイズ
- `COMMENT_SCALE`: コメント領域全体の倍率
- `GIFT_COLOR_MODE`: `original` / `hybrid` / `halloween`
- `SHOW_STAGE_BACKGROUND`: ステージ背景の表示
- `SHOW_COMMENT_FRAME`: コメント領域外枠の表示
- `ICON_MODE`: `profile` / `halloween` / `hidden`
- `SHOW_AMBIENT_EFFECTS`: 背景演出の表示
- `REDUCED_MOTION`: 常時アニメーションの抑制

`ICON_MODE: "halloween"` では、コメントを受信するたびにハロウィン絵文字を抽選します。同じ投稿者でも次のコメントでは別の絵文字になる場合があります。表示中のコメントに割り当てた絵文字は、設定プレビューで再処理されても維持します。

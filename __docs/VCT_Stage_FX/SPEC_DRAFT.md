# VCT Stage FX 初期版仕様ドラフト

作成日：2026-09-15
状態：初期版の仕様記録。2026-09-15に新規テンプレートとして実装を開始。構想時は未採番。2026-09-17に初回公開版1.0.0を採番（現行仕様を参照）。

本書は構想時の仕様記録。実装で具体化した範囲と挙動は[現行仕様](../../VCT_Stage_FX/SPEC.md)、使い方と検証結果は[README](../../VCT_Stage_FX/README.md)を参照する。動き抑制は「画面演出・カード装飾を停止し、コメント移動は継続」とした。

## 目的と位置づけ

VCT Stage Baseの1920×1080ステージ構成へView Comment V3のコメント表示を導入し、コメントビューアと画面演出を一体で設定できる、新しい完成品テンプレートを制作する。

OBSではブラウザソースを画面に合わせ、コメントの配置・大きさ・見た目と画面演出はテンプレート内で調整する。配信者とリスナーのやり取りを見せるため、視認性、操作性、進行を妨げない演出を優先する。

Stage Baseとは別テンプレートとして出発する。MITでの公開を予定するが、派生制作のためのBaseとしては位置づけず、フォークしやすさや汎用拡張仕様を優先しない。保守のため、入力・コメント表示・画面演出の内部的な分離は維持する。

## 初期版の仕様範囲

### ステージとコメント領域

- 論理座標は1920×1080。Baseのレイヤー構成とcontain／cover方式を継承する。
- 操作UIはステージの拡縮から分離する。
- コメント領域は1つ。位置X・Y、幅・高さ、領域全体の倍率を設定する。
- コメント配置はブラウザソース全体ではなく、ステージ内のコメント領域を基準とする。
- 領域全体の倍率は文字・カード・装飾をまとめて拡縮する。領域寸法やカード幅の変更とは区別する。
- 背景は透明を基本とし、Baseの背景色・ローカル画像設定を継承する。

### コメント表示とカード装飾

V3の共通カードと表示設定を継承する。通常・支援・メンバー・固定の表示、名前・アイコン・バッジ・本文・翻訳などを扱う。

| 表示方式 | FXでの基準 |
|---|---|
| 縦積み | 指定領域内へ積み上げる |
| ポップアップ | 指定領域内のランダム位置、または領域内の基準位置とばらつきで配置。全面利用は領域を1920×1080にする |
| Underbar横流し | 指定領域の幅を移動・発車・退場判定の基準とし、下位置も領域基準。複数レーンと振り分けを継承 |
| Underbar横積み | 指定領域を基準に、新着で既存カードを押し出す |

コメント装飾は、なし／ハート／Flash／Starsから選択する。表示方式と装飾は独立して選ぶ。

表示時間変更・方式切替・プレビュー取消の挙動はV3に揃える。縦積みの時間変更は既存カードも表示開始時点から再計算し、Baseの「次のコメントから適用」とは異なる。取消で既に消えたコメントは復元しない。設定変更による再配置・再描画で購読や画面演出を再発火しない。

### 画面演出

- ステージ全体を基準に、Baseの演出Runtime、Plugin登録、実行・待機・停止を活用する。
- 自動発火は支援・メンバーイベントを対象とし、通常コメントでは発火しない。
- 発火判定は受信時に行う。実際の再生開始は画面演出側の待機・同時実行設定に従う。
- Underbarのコメント表示待ちと画面演出は同期しない。演出がカード登場より先に終わる場合も、初期版では許容する。運用上気になる場合に再検討する。
- 「画面演出の全停止」は画面演出の実行中・待機中を対象とする。コメントの削除やカード装飾OFFとは別操作とする。
- 重複入力・ID欠落時の自動発火制限、clear時の処理、演出OFF・ページ非表示・破棄時の停止はBaseの仕組みを基にする。

### 設定UI

OBSの「対話」で設定UIを開き、同じ画面でプレビューする。初期版の配置調整はスライダー、数値入力、上下矢印を使用する。数値入力の確定・補正はV3の操作方式を活かす。

縦に長大なパネルを避けるため、画面内タブで切り替える。以下を初期の分類案とし、項目の実配置は実装時に読みやすさを確認する。

| タブ案 | 主な設定 |
|---|---|
| ステージ | 背景、画面への収まり方 |
| コメント配置 | X・Y、領域の幅・高さ、全体倍率 |
| コメント表示 | 表示方式、方式固有設定、文字・カードの見た目 |
| コメント装飾 | 装飾選択と固有パラメータ |
| 画面演出 | 演出選択、実行・待機、固有パラメータ |

選択中の表示方式・演出に関係する項目を表示し、必要に応じて折りたたみを使う。保存・取消とプレビュー操作はタブ間で共通の場所に置く。表示設定は全タブまとめて保存し、取消は未保存設定を戻す。保存で再読み込みする既存方式を継承する。

UIを隠すBaseの`?ui=0`を継承する。設定項目の最終的な範囲・刻みと配置プレビューの枠表示は、実装時に具体化する。

### 保存とプロファイル

- 基本運用はローカルファイル。新しいローカルサーバーを必須にしない。
- ローカルファイルではフォルダごとに設定を分離する。用途別に分ける場合はフォルダを複製する。
- ローカルサーバー経由のHTTP運用では、V3の`?profile=talk`などによる保存先の分離を継承する。
- プロファイルには背景・コメント配置・表示・装飾・画面演出の設定一式を保存する。コメント履歴や演出の実行・待機状態は保存しない。
- 設定パネルへ編集中のプロファイル名を表示する。専用の作成・一覧・切替UIは初期版に含めない。
- 優先順位は`config_default.js → config.js → ローカル保存差分`。config.jsは全プロファイル共通の基準値。
- V3と同じく、IDは半角英数字・ハイフン・アンダースコアの1～64文字で大小文字を区別する。省略・空欄はdefault、不正値は警告してdefault。ローカルファイルは常にdefault。
- 異なるブラウザ・OBSの保存領域共有は前提にしない。同じプロファイル名は同じ保存環境内で同じ設定先を指す。
- 演出の登録一覧はテンプレート共通とし、プロファイルで分けない。選択する演出とパラメータはプロファイル別にする。
- 登録一覧の追加・解除は表示設定とは別保存で、表示設定の取消対象には含めない。解除された演出を選択している別プロファイルも、次の読込時にフォールバックできるよう確認する。
- Base・V3の既存ローカル設定をFXへ自動移行する機能は初期版に含めない。

## 実装上の方針

Stage Baseを土台に、V3の表示方式・共通カード・装飾をFX用コメントウィジェットへ取り込む。OneSDK購読とVCT SDK正規化を一本化し、正規化した入力をコメント表示と画面演出の判定へ渡す。

V3の画面幅参照、DOM全体への検索、ルートCSS変数は、コメント領域を基準とする処理へ限定する。Underbarの実寸計測では、ステージと領域の拡縮による二重倍率や速度・退場判定のずれを確認する。

位置・寸法・倍率は共通の設定更新処理を通す。将来のマウス操作も同じ処理へ接続できる構造にするが、初期版でマウス操作自体は実装しない。

## 将来候補・初期版の対象外

- 配置編集モードで領域枠を表示し、ドラッグで移動する。
- 領域上のホイールで全体倍率を調整し、数値UIへ反映する。概略調整を目的とし、精密なレイアウトエディタは求めない。
- コメント登場に同期した画面演出。初期版の受信時発火が運用上問題になった場合に検討する。
- 複数コメント領域、複数表示方式の同時利用。
- プロファイル管理専用UI。

将来候補は実装の約束ではなく、初期版へ自動的に含めない。

## 実装開始時に具体化する事項

- 初期配置、スライダーの範囲・刻み、タブ内の項目配置。
- 初期表示は縦積み、装飾と画面演出は控えめとする。具体的な装飾・数値と同梱演出の構成は未確定。
- Baseの動き抑制をV3のカード装飾・移動へどこまで適用するか。画面演出の停止とコメント表示の継続を区別して決める。
- 領域端での装飾のクリップと、領域外に保持するUnderbarカードの扱い。表示上の見切れと内部保持を区別する。
- SDK差分、設定キーの衝突（ステージ背景とコメント背景など）、Plugin登録一覧の保存キーを確認する。
- 対応するわんコメ・OneSDKの版、同梱物・素材のライセンス、公開時の公式条件を実装・配布前に確認する。本書は確認完了を意味しない。
- 製品バージョンは別途決定する。

## 段階実装と検証計画

1. Stage上でV3相当の縦積みとカード装飾、既存画面演出1種類を接続し、受信・表示・発火・停止を確認する。
2. ポップアップ、Underbar横流し・横積み・複数レーンを領域基準へ対応させる。
3. タブ設定UI、位置・寸法・倍率のプレビュー、取消・保存を確認する。
4. ローカルファイルとHTTPプロファイル、共通演出登録一覧の保存分離を確認する。
5. OBSの対話・拡縮・シーン切替・再読み込みと、コメント装飾と画面演出を同時利用した負荷を確認する。

各段階で重複入力、情報欠落、clear、方式切替、タイマー・アニメーションの破棄を確認する。V3の既存検証結果はFXの統合検証済みを意味しない。

当初のドキュメント作成時は実装未着手。現在は現行仕様の範囲を実装し、模擬入力によるブラウザ検証を実施。シーン切替と長時間負荷の評価は継続中。
